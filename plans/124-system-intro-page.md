## 1. 결론

- 참고 사이트의 역동성은 **세 장치**에서 나온다. ①**장면 고정 스크롤** — 장면 높이 260~520vh 안에 100vh짜리 `position: sticky` 무대를 두고, 장면별 진행률 0~1을 매 프레임 계산한다. ②**3D 세계 하나에 정거장 여러 곳** — 고정 전체화면 캔버스에 장면별 피사체를 z축으로 늘어놓고, 카메라가 진행률에 따라 정거장 사이를 날아간다(three.js + 블룸 후처리). ③**진행률에 묶인 글자 연출** — 레이어 페이드, 줄 단위 강조(사용자가 짚은 `#s2`), 카운터, 3D와 동기화된 목록 강조. 외부 라이브러리는 three.js 하나이고 나머지는 약 500줄의 바닐라 JS다.
- 이 시스템에 옮기면 같은 세 장치 위에 **장면 9개**를 올린다(§4). 내용은 docx에서 가져오고, **모든 자산을 로컬에 둔다**(폐쇄망). 3D를 못 쓰는 환경(VDI·소프트웨어 렌더링)에서도 글자 연출은 온전히 돈다(§5.4).
- **위험은 두 가지다.** ①**폐쇄망·VDI 성능** — 은행 업무 PC는 GPU가 없거나 소프트웨어 렌더링일 수 있다 → 품질 3단 자동 강등. ②**과대 표현** — docx는 *"도입 전후 실측 비교 미실시"*·*"목표이지 달성치가 아님"*·*"예측·자동 조치는 코드 착수 전"*이라고 스스로 밝힌다. 화려한 페이지가 이를 달성한 것처럼 보이게 하면 안 된다 → 현황 배지를 그대로 싣고, 숫자는 코드로 셀 수 있는 것만 싣고, 사실 가드 테스트를 둔다(§3).
- 대조 결과 **docx와 코드가 어긋나는 곳이 3건**이다(§3.2). 소개 페이지는 코드 실측을 따르고 문서 쪽 정정은 문서 소유자에게 알린다(G-7).

## 3. 내용 원천과 사실 대조

### 3.1 표기 원칙

1. **현황은 docx 표기를 배지로 그대로 싣는다** — 구현 완료 / MVP / 진행 중 / 계획 / 미연동. 계획 항목을 완료처럼 연출하지 않는다(3D에서도 계획 항목은 점선·와이어프레임으로 그린다 — §4).
2. **달성 수치는 싣지 않는다.** docx §1 *"도입 전 정량 수치 미제시"* · §4 *"도입 전후 실측 비교는 미실시"*. 목표치(액션 가능 비율 30~50%, 교대당 페이지 2건 이하, 사건 전환율 20% 이상)를 싣는다면 반드시 「목표」 표지를 붙인다 — 권고는 **싣지 않음**(카운터 연출과 섞이면 달성치로 읽힌다).
3. **「예방·예측·자동 조치」는 목표로만 쓴다** — docx §6 *"장애 예방은 목표이지 실증된 기능이 아님"*.
4. **카운터 숫자는 코드·설정으로 셀 수 있는 사실만** 쓴다. 이 숫자들은 사실 가드 테스트가 코드와 대조한다(§6 T-9).
5. 알람 입자 같은 연출 수량은 실데이터가 아니다 — 수치를 표시하지 않고 캡션에 「연출 예시」를 적는다.
6. 페이지 바닥에 **기준일과 근거**를 적는다 — *"2026-09-29 추진 현황 기준 · 도입 효과는 측정 전"*.

## 5. 기술 설계

### 5.1 파일 배치 (D-139 — 본체 웹 UI는 `src/static`)

| 파일 | 역할 |
|---|---|
| `src/static/intro.html` | 마크업과 **글자 전부**(JS 없이도 읽힘) · 현황 배지·사실 숫자 데이터 블록 · importmap |
| `src/static/intro/intro.css` | 토큰 · 장면 레이아웃 · 반응형 · reduced-motion |
| `src/static/intro/scroll.js` | 장면 진행률 · `data-show` · 줄 강조 · 카운터 · 진행 막대 · 점 내비 · 키보드 — **DOM만 다루고 3D 의존 0** |
| `src/static/intro/world.js` | three.js 세계 — 정거장별 `build*`/`update*` 함수 · 카메라 · 품질 등급 · FPS 감시 |
| `src/static/vendor/three/` | three.js **r160** `three.module.min.js` + 블룸 경로 addons(EffectComposer · RenderPass · ShaderPass · MaskPass · Pass · UnrealBloomPass · OutputPass · CopyShader · LuminosityHighPassShader · OutputShader) + `LICENSE`(MIT) · 버전·sha256을 `README`에 기록 |
| `src/api/server.py` | `/intro` 라우트 1개(`FileResponse` — 기존 HTML 화면과 같은 형태) |

- **의존 방향은 한쪽이다**: `scroll.js`가 상태(`active`, `p[]`)를 만들고 `world.js`는 읽기만 한다. 3D가 실패해도 글자 연출에 영향이 없다.
- **빌드 단계를 두지 않는다** — 기존 `src/static`처럼 평문 JS다. three.js는 개발 맥에서 한 번 내려받아 커밋한다(런타임 외부 요청 0).

### 5.2 시각 체계

- **바탕은 어둡게 고정**(G-3) — 블룸·발광 연출은 어두운 바탕을 전제로 한다.
- 색: 잉크 `#04060d` · 시안 `#5ce1ff`(에이전트) · **KB 옐로 `#FCAF16`**(사람 — `img/kb-mark.svg`의 심벌 색) · 적색(알람) · 민트(구현 완료). 대비는 어두운 바탕 위 AA 이상.
- 서체: **Pretendard Variable**(본문·디스플레이 800) + **D2Coding**(모노 라벨) — 둘 다 이미 `src/static/fonts/`에 있다. 세리프 디스플레이는 G-4.
- 브랜드: 기존 포탈과 같은 수준 — KB 심벌(`img/kb-mark.svg`) + 「KB AIOps 포탈」 표기. 새 로고 자산을 만들지 않는다.

### 5.3 3D 구성

- 정거장 A~E를 z축으로 약 50 단위 간격으로 둔다. 모든 형상은 **코드로 생성**(상자·캡슐·구·링·점·선·튜브) — 모델 파일 0.
- 글자 라벨·카드·브리핑은 2D 캔버스 텍스처로 그리고, 그리기 전에 `document.fonts.load()`로 Pretendard를 최대 1.8초 기다린다.
- 별가루 입자(상 2,000 / 중 800)와 정거장 사이 빛줄기는 참고 사이트와 같은 방식이다.

### 5.4 품질 3단 · 폐쇄망 성능

| 등급 | 조건 | 내용 |
|---|---|---|
| **상** | WebGL2 · 하드웨어 렌더러 · 데스크톱 | 블룸 · 입자 전량 · 픽셀 비 ≤ 2 |
| **중** | 모바일·저사양 · 소프트웨어 렌더러 의심 · FPS 강등 | 블룸 끔 · 입자 × 0.4 · 픽셀 비 1 · 안티앨리어싱 끔 |
| **정지** | WebGL 생성 실패 · `prefers-reduced-motion` · `?quality=static` | 캔버스 없음 · 장면별 CSS 그라데이션 배경 · 글자 연출만 |

> **2026-09-30 개정(§10)**: VDI 등(가상·소프트웨어 GPU 또는 WebGL 없음)에서는 reduced-motion이 정지를 부르지 않고, 정지 배경이 장면별 사전 렌더 반복 영상이다. 일반 GPU PC는 위 표 그대로다.

- **판정**: WebGL 컨텍스트 실패 → 정지. `WEBGL_debug_renderer_info` 렌더러 문자열이 `SwiftShader`·`llvmpipe`·`Microsoft Basic Render`면 중으로 시작. 실행 중 **최근 2초 평균 프레임 시간 > 33ms면 한 단계 내림**(올리지 않는다).
- 발표자 강제: `?quality=high|mid|static`.
- 탭이 숨으면 렌더를 멈춘다(`document.hidden`).
- **예산**: 자체 JS ≤ 60KB · 벤더 three.js 약 700KB(캐시) · 글자 첫 표시는 3D를 기다리지 않음 · 개발 맥 1080p 상 등급 평균 ≥ 50fps.

### 5.5 접근성

글자는 DOM에 있고 캔버스는 `aria-hidden` · `lang="ko"` · 키보드 장면 이동 · `:focus-visible` · 카드 링은 `sr-only` 목록과 `aria-live` 캡션 병행 · reduced-motion이면 카메라 비행 대신 컷 전환.

### 5.6 비목표

실시간 API 데이터 연동(카운터는 정적 사실) · 분석 태그·외부 폰트·CDN · 다국어 · CMS·편집 화면 · 참고 사이트 코드·문구 복제.

### 10.4 확인하지 못한 것

- **사용자 VDI의 렌더러 이름** — WebGL은 된다고 확인했으나 렌더러 문자열은 모른다. `VIRTUAL_GPU`에 걸리지 않는 vGPU(예: 일반 NVIDIA 이름으로 보이는 프로파일)라면 일반 PC로 판정돼 reduced-motion에서 정지(기존 동작)가 된다. 콘솔 `__intro.state.vdi`와 렌더러 이름을 한 번 확인할 것.
- **VDI에서의 영상 재생 부하** — GPU 없는 환경의 VP9 720p 소프트웨어 디코드는 실측하지 않았다.
