# Plan: 시멘틱 라우터 분류 지시문 개선 (Plan 79 트랙 A)

> **Spec**: `SPEC-semantic-router-instruction.md` v3 (승인 완료)
> **승인 사항**: FabriX = **KBGenAI 모드**(트랙 C logprob 이월) · A-1 **즉시 적용**(플래그 없이)

## 컴포넌트와 의존성

```
T1 프롬프트 구조 테스트 (TDD — 먼저 실패)
     │
     ├─→ T2 A-1 규칙 5 제거        (S1)
     ├─→ T3 A-2 신뢰도 대역 예시    (S2)  ← T2에 의존(규칙 5가 없어야 저대역 예시가 모순 아님)
     ├─→ T4 A-3 클래스 정의 일원화  (S4)
     ├─→ T5 A-4 편중 완화           (S3)  ← T4와 같은 예시 블록을 만짐 → 순차
     └─→ T6 A-5 fault_diagnosis 배치 (S5)
     │
T7 A-7 intent_planner 중복 정리 (독립)
     │
T8 전체 회귀 + arch_check (S7·S8)
```

**순차 필요**: T3·T4·T5는 같은 few-shot 블록을 수정하므로 한 번에 하나씩.
**병렬 가능**: T6·T7은 다른 구간이라 독립.

## 위험과 완화

| 위험 | 완화 |
|---|---|
| **A-1 즉시 적용 = blast radius**(코드 게이트가 처음 작동, 종전 통과 DB 탈락 가능) | 기존 24개 라우팅 테스트 무회귀 확인. 변경 근거를 주석으로 남겨 롤백 지점 명확화 |
| 예시 수정 중 **멀티 DB 예시 훼손**(79 §1.1 불변식 위배) | T1에서 S6(멀티 DB 예시 ≥1) 단언을 먼저 넣어 방지 |
| 예시 개수 줄이다 **커버리지 손실**(alarm_query 패턴) | 전용 패턴 절(`:94-107`)은 유지 — 예시만 조정 |
| `fault_diagnosis` 절 이동 시 **조건부 삽입 로직 파손** | `_build_router_prompt`의 조립 순서를 확인하고 옮긴다 |
