**생성 방법(누락 방지)**: W2 갱신도 같은 생성기로 다시 만들었다 — 현재 중립 키는 작업 트리 `fields.py`를, 기준선 대조는 `git show 54e1597:…/fields.py`를 같은 AST 규칙(상수 dict 루프 `METRIC_FIELDS`·`REALTIME_EXTRA_FIELDS`·`APPLICATION_STATUS_EXTRA`·`METRIC_CATALOG_SCOPES` 포함)으로 읽어 「구현(작업 트리)」 칸을 정했고, 허용목록은 작업 트리 `allowlist.py`를 로드했다. 표 A~F와 §8 집계는 세션 scratchpad의 생성기(`cov/gen.py` · `cov/fields_ast.py` · `cov/data_caps.py` — **저장소 밖**)가 만들었다. 경로는 스펙 `paths[*]`의 메서드를, 인자는 `paths[*].get.parameters`를, 필드는 `components.schemas[*].properties`와 api-v2 인라인 응답 스키마를 **순회**해 뽑았다. 현재 중립 키는 `fields.py`를 AST로 읽어(파서별 `raw.get("…")` → dict 키) 채웠고, 허용목록 상태는 `allowlist.py`의 `ALLOWED`를 그대로 로드해 판정했다. v2 매뉴얼 13경로는 JSON 스펙이 없어 매뉴얼 본문(URL 형식·응답 예)에서 인자·필드를 빠짐없이 옮겼다. 생성기는 「스펙 데이터 GET 집합 = 표 A 스펙 행」「스키마 집합 = 표 C 스키마」「표 A 질문 ID ⊂ 표 F」「43사례 전부 표 F」「목표 보기 25개 각각 기능 ≥1」을 단언한다. 생성기가 저장소에 없으므로 이후 갱신은 표를 직접 고친다(W9에서 저장소 스크립트로 들일지 검토).

**완료 조건(`plans/134` §4.1·§6-1)** = **데이터 제공 GET 경로·지원 인자·필드의 미처분 누락 0**. 「처분됨」은 행마다 ① 구현 Wave 배정 또는 ② 사유 있는 처분(미지원·제외·거부·구조) 중 하나가 있다는 뜻이다. **Wave 배정은 구현 완료가 아니다** — 수용 기준 §6-1은 해당 Wave의 구현·계약 테스트 통과로 판정하며, API가 허용돼도 호출부·사용자 기능이 없으면 미완이다.

## 3. 표 B — 인자 행

(capability, 인자) 1행 — 스펙 `parameters` 전수(경로 변수 포함) + v2 매뉴얼 URL 형식의 인자 전수. 「지금」 칸은 작업 트리 `allowlist.py` `ALLOWED`를 로드해 판정한 허용 여부(허용(필수·선택) · **허용 밖** · 경로 미허용 · 경로 변수 형식)와 `api.py`의 실제 전달 근거다. 「구현(작업 트리)」 칸은 §1 표기이고, ✔ W1·W2 행의 시험 칸은 **실제 시험 이름**(`apm_gateway/tests/` 아래 `test_w1_coverage.py`·`test_w2_coverage.py`·`test_w2_fix_regressions.py` — `파일::함수`)이다. 기준선 행과 미구현 행의 시험 칸은 계획 ID(「(계획)」)다.

- **`time_pattern`**(스펙 11개 경로) — **미지원 — epoch ms만 쓴다(plans/87 §5.5 · U-14) · 같은 데이터라 잃는 정보 없음**. 테스트는 공통 `T-ALLOW-no-time_pattern`(계획 — 어느 도구 호출에도 이 키가 없음을 목 서버 hits로 단언).
- **`token`**(전 경로) — **거부(보안 — Authorization 헤더만)**. 표 끝 1행으로 쓴다.
- **COV-DBM-DOMAIN**은 W2에서 하지 않고 **W3 유지**다(팀 리드 지시 — 지금 `apm_metrics(scope=domain)`은 「W3 예정」 `invalid_argument`) — 그래서 그 5행의 목표 Wave를 W2 → W3로 고쳤다.
- 모든 인자는 코드가 타입·범위·필수값을 검증하고, 모르는 값은 버린 뒤 다른 조회로 성공 처리하지 않는다(§4.2 · G-7). 자유 URL·임의 API 경로는 받지 않는다(D-122 취지).

## 4. 표 C — 응답 필드 행

(스키마, 필드) 1행. **같은 스키마를 여러 경로가 쓰면 1행으로 쓰고 capability 열에 모두 적는다**(같은 내용 반복 방지 — (capability, 필드) 조합 수는 §8). 스펙 `components.schemas` 35개 전부(봉투·쓰기 본문·시험 스키마 포함) → 스펙 api-v2 인라인 응답 스키마(기계 평탄화) → 본문(텍스트·미공개 객체) → v2 매뉴얼 응답 예 순이다.

- **현재 중립 키** = 작업 트리 `fields.py` AST 추출(파서 `parse_domain`:152 · `parse_instance`:160 · `parse_realtime`:196 · `parse_active_service`:215 · `parse_transaction`:252 · `parse_event`:287 · `parse_error`:308 · `parse_metric_point`:325 · `parse_application_status`:354 · `parse_call_status`:370 · 카탈로그 `METRIC_CATALOG_SCOPES`:411 · `parse_source_change`:445). 「버림」 = 파서가 읽지 않음 · 「버림(경로 미호출)」 = 경로 자체를 부르지 않음.
- **구현(작업 트리)** = 기준선(`54e1597`) 파서와 대조해 정했다 — 기준선에서 읽고 도구가 행에 싣던 것은 ✔ 기준선, 새로 읽은 것은 ✔ W1(W2 스키마는 ✔ W2), 기준선에서 파서만 읽고 도구가 싣지 않던 것(오류 기록 필드 · 이벤트 `domainName`)은 ✔ W1이다. 텍스트 칸에 붙은 「전문 W2」는 W2가 300자 절단을 걷었다는 뜻이다.

- **처분 공통 전제**: 모든 응답은 원본 수신 직후·출력/로그 생성 전에 공통 자격증명 제거 경계를 지난다 — **W0-B로 구현됨**(`apm_gateway/apm_gateway/domain/credentials.py` · `client.py:162-192` · 시험 `test_credentials.py`). 「반환」은 그 경계 뒤 원값을 유지한다는 뜻이고, 「전체 파일」도 D-262 마스킹·소유권을 따른다. 개인정보 원값 표시(G-11)는 미결이므로 「현행 마스킹(G-11)」 행은 지금 규칙을 그대로 적용하며, 규칙이 없는 필드는 원값이 통과함을 그대로 적었다(표 E E-21).
