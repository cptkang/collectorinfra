벤더별 AIOps 기능 구현 레퍼런스

Dynatrace · Datadog · Splunk ITSI · Moogsoft · BigPanda · New Relic가 각 기능을 실제로 어떻게 구현하는가 → collectorinfra 구현 기준 · AIOps 아키텍트 · 2026-07
이 문서의 용도. 각 AIOps 기능을 선진 솔루션이 어떤 메커니즘·알고리즘·전제조건으로 구현하는지 벤더별로 나란히 정리한 구현 기준(reference standard)이다. 각 기능 표의 맨 아래 초록 행(▶ collectorinfra 기준)이 이 벤더 구현들을 종합해 도출한 우리의 구현 방침이다. 관통하는 설계 원칙은 "결정적 계산(규칙·그래프·통계) + 보조적 LLM/ML" — Dynatrace Davis의 deterministic 인과 엔진, 최신 연구(토폴로지 인지 RCA·arXiv 2606.20758)와 동일하며 collectorinfra의 D-035 원칙과 정합한다.
