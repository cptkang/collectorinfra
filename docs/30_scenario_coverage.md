## 판정 어휘

| 열 | 값 | 뜻 |
|---|---|---|
| 프롬프트 트리거 | `가능` | 사용자 프롬프트 한 문장으로 이 기능을 태울 수 있다 |
| | `불가` | 트리거가 TCP 소켓/알람 이벤트/UI 경로다. 별도 트랙에 위임한다(§3.6) |
| | `미분류` | **자동 분류하지 않았다.** 사람이 확정해야 한다 - 분모를 지어내지 않는다 |
| 상태 | `구현` / `미구현` / `로드맵` / `미분류` | 시나리오 작성 대상 판정 |
| | `부분` | 일부 랜딩 · 잔여 있음(`plans/INDEX.md` `-WIP`). 미커버 사유 판정에서는 `구현`과 같이 다룬다 |
| 비고 | `내부 …` | 특정 프롬프트가 아니라 **모든 질의가 경유하는 구조**다 - 별도 시나리오 대신 전 군이 간접 커버한다(`불가`) |
| | `실행 환경 부재 …` | 이 머리로 시작하면 `coverage_gap` 이 시나리오 0건을 `카탈로그 미작성` 이 아니라 `실행 환경 부재` 로 분류한다(환경 전제 - 예: 폐쇄망 전용) |

**`미분류`를 `불가`로 밀어 넣지 않았다.** 분모에서 조용히 빼면 커버리지가 부풀려진다.
2026-09-11 판의 미분류 28건은 2026-09-29 `plans/122` 부록 A로 확정해 **미분류 0건**이다. 새 계획서가 생기면
행을 더하고, 분류가 서지 않으면 `미분류`로 둔다 - 건수는 `coverage_gap.md` 첫머리에 남는다.
