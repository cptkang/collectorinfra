# 30. 시나리오 커버리지 매트릭스 (plans/94 Wave S0 산출)

> **작성일**: 2026-09-11 · **생성**: `plans/` 전건 실측 + `plans/94` §1.5 클러스터/제외표의 기계 판독본
> **용도**: *"plans 폴더의 기능들을 테스트"* 라는 요건이 충족됐는지 판정하는 **분모**다.
> 이 표가 없으면 `coverage_gap.md`(분석기 산출)가 미커버 사유를 넷 중 하나로 분류할 수 없다(§6.4).
> **소비처**: `scripts/scenario/analyze.py:parse_coverage_doc` 가 `| plans/NN |` 로 시작하는 행만 읽는다.

## 판정 어휘

| 열 | 값 | 뜻 |
|---|---|---|
| 프롬프트 트리거 | `가능` | 사용자 프롬프트 한 문장으로 이 기능을 태울 수 있다 |
| | `불가` | 트리거가 TCP 소켓/알람 이벤트/UI 경로다. 별도 트랙에 위임한다(§3.6) |
| | `미분류` | **자동 분류하지 않았다.** 사람이 확정해야 한다 - 분모를 지어내지 않는다 |
| 상태 | `구현` / `미구현` / `로드맵` / `미분류` | 시나리오 작성 대상 판정 |

**`미분류`를 `불가`로 밀어 넣지 않았다.** 분모에서 조용히 빼면 커버리지가 부풀려진다.
28건이 사람 확정 대기 상태이며, 이 수치 자체가 리포트에 남는다.
