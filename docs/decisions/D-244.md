- **결정일**: 2026-09-22 | **상태**: 확정 (이동 완료) | **번호**: 등재 직전 실측 2026-09-22 — `## D-` 헤더 최댓값 **D-243** · 「변경 이력」 표 최댓값 **D-243** · 「채번 이력」 표 예약에 244 없음 → **D-244**
- **배경**: 루트에 `SPEC-*.md` 47개와 `CAPABILITY-MAP-*.md` 13개가 쌓여 있었다. 원인은 `agent-skills` 플러그인 기본값이다. `spec-driven-development` 스킬은 *"Save the approved map at the project root and each module's spec alongside it"*(`SKILL.md:65`), `/spec`은 *"Save the spec as SPEC.md in the project root"*(`commands/spec.md:17`)라고 지시한다. 사용자 지시: *"SPEC-* 파일들을 별도의 폴더에 저장하여 관리하라. 향후 SPEC 관련 파일이 별도의 폴더에 저장되도록 정책을 정의하라"* · *"CAPABILITY-MAP-* 관련 파일도 같은 폴더에서 관리되도록 같이 정리하라"*
- **결정**:
  - ①**`spec/`에 평면으로 둔다**(하위 폴더 없음). 대상은 기능 맵 `CAPABILITY-MAP-*.md`와 모듈 스펙 `SPEC-*.md`다. 모듈이 하나뿐인 단일 스펙도 `spec/SPEC-<slug>.md`로 쓴다
  - ②**플러그인 기본값을 이 저장소에서 대체한다.** 규칙의 정본은 CLAUDE.md 「SDD 산출물 위치」다(매 세션 로드되어 스킬 기본값보다 우선한다)
  - ③**루트 `SPEC.md` 생성 금지** — 개발 맥 APFS는 대소문자를 구분하지 않는다. `ls -i SPEC.md spec.md`가 같은 inode(278454801)를 가리킨다. `/spec` 기본값을 따르면 원 요구사항 `spec.md`(41KB)를 덮어쓴다
  - ④범위 밖 두 가지는 종전대로 둔다. 원 요구사항 `spec.md`는 루트에 남는다(`.claude/agents/` requirements-analyst·team-lead·implementer가 루트 경로로 읽는다). `tasks/plan-*.md`·`todo-*.md`도 `tasks/`에 남는다(스킬 기본값 `tasks/`와 같다)
  - ⑤**기존 참조는 치환하지 않는다.** 파일명만 적은 참조(`SPEC-x.md`)는 `spec/`에서 찾는다. 새 문서는 `spec/SPEC-x.md`처럼 경로를 적는다
- **근거**: 폴더 이름을 단수 `spec/`로 정한 이유는 `/build`가 스펙을 *"`SPEC.md` at the repo root, `docs/SPEC.md`, or a file under `spec/`"*(`commands/build.md:31`)에서만 찾기 때문이다. `specs/`나 `docs/specs/`로 정하면 `/build`가 스펙을 못 찾고, 클린 기준선 검사(`build.md:32`)도 스펙 파일을 미예상 변경으로 본다. 참조를 치환하지 않은 이유는 셋이다. 첫째, 참조 197건(이동 파일 자신·CLAUDE.md·이 문서 제외, 133개 파일) 대부분이 이력 기록(결정·변경 이력·계획서 개정 표)이다. 둘째, 코드 트리(`src`·`tests`·`noise_gate`·`sre_agent`·`mcp_server`·`scripts`·`config`) 71개 파일의 독스트링·주석까지 번진다. 셋째, 파일을 여는 코드 0건 · 마크다운 링크·상대경로 0건이라(실측 `git grep`) 이동해도 동작이 끊기는 곳이 없다
- **대안(기각)**: `specs/`·`docs/specs/`(`/build`가 인식하지 못한다) · 참조 197건 일괄 치환(이력 문서 변경 · 병행 세션과 충돌할 면이 넓다) · `spec.md`도 함께 이동(에이전트 정의 3종의 경로를 바꿔야 하고 요청 범위 밖이다) · 루트 생성 차단 훅·테스트(요청은 정책 정의 — 필요하면 후속으로 둔다)
- **구현**: 파일 60개를 `spec/`으로 이동(내용 변경 0 · `git diff -M` rename 60건) · `CLAUDE.md` 「SDD 산출물 위치」 절 신설 · 23행 조합 문구 · 저장소 지도 `spec/` 행
