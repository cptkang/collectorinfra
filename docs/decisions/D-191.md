## D-191. 설정 옵션 상세 설명 패널 — **큐레이션 + 자동 파생 2계층, 반영 시점은 언제나 카탈로그 실측**

- **결정일**: 2026-08-31 | **상태**: 확정 (구현 완료) | **번호**: `## D-` 헤더 최댓값 **D-190** · 「변경 이력」 표 최댓값 **D-190** · 「채번 이력」 표 예약(D-105·115·134·158·163~168·176) 대조 → **D-191**(2026-08-31 실측). ⚠ 작업 착수 시점에는 D-190이 최신이라 그 번호로 구현했으나, 같은 날 D-190이 이벤트 알람 필터에 선점돼 **19개 파일을 D-191로 일괄 재부여**했다.
- **배경(사용자 지시)**: *"admin 페이지의 설정 옵션이 옵션 선택에 따라 어떻게 동작되는지 사례를 들어 설명하는 기능을 추가하라. (…) 기능적으로나 성능, 안정성 측면에서 운영자가 설정할 때 참고할 수 있도록 설정 옵션별 설명 페이지를 화면 오른쪽에서 별도로 보여주는 식."* D-129가 만든 설정 화면은 **무엇을 설정할 수 있는가**(타입·기본값·반영 시점)까지만 답했다. 실측하니 309개 중 **설명이 붙은 것은 174개**였고 그마저 `.env.example` 주석 한 줄이라, "이 값을 바꾸면 무엇이 어떻게 달라지는가"는 코드를 읽어야만 알 수 있었다.
- **결정**:
  - **원천을 2계층으로 나눈다.** ①**큐레이션** `config/settings_help/{그룹}.yaml` — 사람이 쓴 사례·성능·안정성·권장값. ②**자동 파생** — 큐레이션이 없는 키는 카탈로그 메타(타입·기본값·선택지·반영 시점·오버라이드·소비 여부)와 **키 이름의 트레이드오프 축**에서 결정적으로 문장을 만든다. **패널이 비는 항목이 없다**(테스트가 309키 전건 단언).
  - **자동 파생에 LLM을 쓰지 않는다.** 같은 입력이면 항상 같은 문장이다. 축(`_AXES` 10종 — 시간 예산·조회 상한·재시도·임계·캐시 수명·시간창·주기·비율·동시 실행·보존 기간)을 **모르면 방향 설명을 지어내지 않고 타입·기본값만 안내한다**. 운영 지식을 코드가 창작하면 그럴듯한 오답이 된다.
  - **「반영 시점과 제약」(`operational`)은 큐레이션 여부와 무관하게 언제나 카탈로그 실측으로 만든다.** 재시작/리로드/즉시·OS·`.encenv` 오버라이드·미소비·시크릿은 카탈로그가 아는 사실이고, YAML에 손으로 옮겨 적으면 **코드가 바뀌었을 때 문서만 옛말을 하게 된다**. 같은 이유로 옵션의 `is_default`·`is_current`도 **YAML 값을 무시하고** 카탈로그·실효값으로 덮어쓴다(테스트로 고정).
  - **1차 큐레이션 범위 = 사용자가 고른 4개 축 228건**(전역·LLM·쿼리 정책 51 / 노이즈 게이트 94 / 알람·Text2SQL 52 / 보안·인증·감사 31). 나머지 81건은 자동 파생이다. **커버리지 게이트**(`test_t2_curated_groups_have_full_coverage`)가 이 그룹의 100%를 단언하므로, `config.py`에 필드가 늘면 **설명 없는 항목이 조용히 늘기 전에 CI가 먼저 실패한다**(D-129 T1과 같은 성격).
  - **패널 트리거는 행 클릭이 아니라 전용 `?` 버튼이다.** 행 전체를 클릭 대상으로 삼으면 토글·입력 위젯 조작과 충돌한다.
  - **도움말은 단건 엔드포인트**(`GET /admin/settings/help/{env_key}`) **+ 프런트 캐시**다. 309건 전량을 `/settings/schema` 응답에 실으면 화면 로드가 무거워지는데, 실제로 열어 보는 것은 한 번에 하나다.
  - **도움말 실패가 설정 화면을 막지 않는다.** YAML이 깨지거나 없으면 경고 로그만 남기고 자동 파생으로 내려가고, 현재값 메타 계산이 실패해도 본문은 나간다(테스트로 고정).
- **대안 기각**: **런타임 LLM 생성** — 비결정적이고 과금 경로이며(D-127) 운영 사실을 창작한다 · **설명을 `config.py` 주석에서 긁어 쓰기** — 주석은 개발자용 근거이지 운영자용 사례가 아니고, 독스트링의 스키마 리터럴이 `overfit_check`에 걸린다(D-179 실사례) · **`DESCRIPTION_OVERRIDES`(코드 상수) 확장** — `settings_catalog.py`가 이미 1061줄이고, 정본 YAML은 `config/`에 둔다는 저장소 규약과도 어긋난다 · **모달** — 값을 만지면서 읽는 용도라 목록과 동시에 보여야 한다(그래서 sticky 오른쪽 열).
