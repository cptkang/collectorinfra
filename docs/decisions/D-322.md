- **결정**:
  ① **선택 주체** — 주 동작은 채팅의 **말 지목**, 화면 선택은 보조(Q1).
  ② **소스별 사전 정의 단어** — 레지스트리 `solutions[apm].sources[]` 행마다 `terms`(위치어·이름)를 두고 제니퍼 소스 선택은 **이 목록만** 본다. 폴스타 위치어 표(`locations`)·DB → 존 경로를 거치지 않는다(**D-287 ⑥ 개정** · Q2·Q3). 같은 단어를 여러 소스에 둘 수 있다(Q4). 매칭은 기존 `term_in_text`·D-271 제외어·긴 단어 우선. **이 단어는 시스템 유사어가 아니다** — `target_db_hints`·D-293 ③ 처리기 고정에 넣지 않고 APM task 안에서만 쓴다(D-293 ① 「위치어와 겹치는 이름은 소스 유사어에서 제외」 불변).
  ③ **되묻기** — 사용자가 쓴 단어가 **소스 둘 이상에 걸리면** 조회하지 않고 걸린 소스 중에서 고르게 한다(Q4). 화면 선택·단어·지목·승계가 **모두 없으면** 사용 가능 소스 + 「전체」 중에서 고르게 한다(Q5 — D-287 ⑤의 「허용된 전 소스」 기본 조회를 소스 ≥2 배포에서 바꾼다 · 인가는 불변). 되묻기는 그 APM task만 조회 0이고 같은 질의의 다른 task는 진행한다. 소스 1개 배포는 되묻지 않는다.
  ④ **승계** — 되묻기 답(버튼·글)·말 지목·화면 선택은 같은 대화에서 승계하고 「승계 중」으로 표시한다. 새 단어·지목·× 해제로 바뀐다(Q6). 지시어 후속은 직전 대상 행의 `apm_source_id`를 쓴다(`plans/130` M-5 흡수).
  ⑤ **화면** — 스코프 칩에 「제니퍼 소스」 축(`/scope/options` `apm_source` · APM 활성 ∧ 사용 가능 소스 ≥2 ∧ `apm` 권한일 때만) · 요청 칸 `selected_apm_source_ids`(시스템 단위 `selected_sources`와 분리).
  ⑥ **소스 추가 = 설정만** — 게이트웨이 `.env`(`JENNIFER_SOURCES`·접두 키) + 레지스트리 한 행(`id·label·zone·terms`). 본체 기동 시 `gateway_health` 1회로 정합을 점검하고, **레지스트리에만 있는 소스(미연결)는 되묻기 선택지·화면 축에서 뺀다**(점검 실패 시 레지스트리 전 소스 사용 가능). 분해 프롬프트 소스 칸은 레지스트리 기준 그대로(렌더 결정성). 관리 화면 카드·CLI로 불일치를 드러낸다.
  ⑦ **범위 밖·불변** — 소스 단위 권한 없음(D-287 ⑤ 인가 유지) · 신규 `enable_*` 없음(활성 = APM 활성 ∧ 레지스트리 소스 ≥2 — 그 밖 배포 바이트 불변 · D-162) · 알람·노이즈 게이트·조사 경로 불변 · 2단 기준(1단·3단은 각 잔여).
