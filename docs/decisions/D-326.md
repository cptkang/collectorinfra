## D-326. 시연 세션 실행기 — **`scripts.scenario`와 분리된 `scripts/demo` · 떠 있는 서버에 질의해 웹 대화 이력으로 남김 · 판정 없음 · 자리표 + 환경 값 파일(운영 값은 저장소 밖)** (사용자 지시 2026-10-13 「기존 scripts.scenario와 별개인 시연용 스크립트를 작성해주고, 실제 데이터가 필요한게 있다면 apm_bench처럼 실제 데이터를 입력하도록 하는 가이드도 같이 작성하시오」)

- **결정일**: 2026-10-13 | **상태**: 확정 · 구현(커밋 없음 · 실 서버 대상 실행 미검증)
- **배경**: 사용자는 시연 자리에서 「무엇을 조회할 수 있고, 어떤 데이터가 연동돼 있으며, 복합 질의를 얼마나 잘 처리하는지」를 웹 대화 이력으로 보여 주려 한다. 기존 시나리오 러너(`scripts.scenario` · D-216)는 폴스타 기능 회귀용이다. 게다가 자식 서버를 띄우고 체크포인트를 런 전용 파일로 격리한다(`runner.py` `CHECKPOINT_DB_URL` 오버라이드). 그래서 이력 목록(앱 DB `query_thread_turns`)에는 대화가 보이지만, 웹에서 그 대화에 이어 물으면 맥락이 없다.
- **결정**:
  ① **별도 실행기** `python -m scripts.demo` — 서버를 띄우지 않고 `--base-url`의 **이미 떠 있는 서버**에 웹 UI와 같은 계약(`/query/stream` · `/query/file/stream` · `/auth/login`)으로 질의한다. 세션 하나 = thread_id 하나 = 웹 대화 1건이다. 판정·기대값은 두지 않는다(판정은 `scripts.scenario`의 몫).
  ② **카탈로그** `testdata/demo/sessions.yaml` — 8군(G1 조회 기능 · G2 연동 소스 · G3 교차 소스 · G4 복합 질의 · G5 대화형 · G6 문서 산출 · G7 안전성·정직성 · G8 운영 보조) · 세션마다 `requires`(필요 소스)와 `core`(핵심 세트).
  ③ **실제 데이터 입력** — 질의의 환경 의존 값은 `{{자리표}}`로 쓰고 환경 값 파일(`sources` · `values` · 자동 응답 우선순위)이 채운다. 커밋본은 합성 값(`env.sandbox.yaml`)과 빈 템플릿(`env.closed.template.yaml`)뿐이다. 운영 값 파일은 저장소 밖에 두고 `--env-file`로 넘긴다(apm_bench `--placeholders` 선례 · 반출 금지). 저장소 안에 둔 경우를 막는 `.gitignore` 보호선을 둔다. 빈 자리표는 실행 전에 멈춘다(`--check`).
  ④ **역질문** — 웹 칩 확인 버튼과 같은 구조화 필드로 자동 응답한다(존 = 우선 존 또는 첫 선택지 · 소스 선택 = 제시 소스 전부 · 양식 미해결 열 = 비움 · 승인 = 「승인」). 선택지 없는 글 질문, 그리고 `--clarify stop`이면 세션을 멈추고 웹에서 발표자가 답한다. `expect_clarify` 턴은 다음 턴이 답한다.
  ⑤ **이력 소유** — 로그인 사용자(`--user`) 또는 인증이 꺼진 서버의 브라우저 식별자(`--client-id` → `X-Client-Id`)로 묶인다(D-248 `history_owner`).
  ⑥ **과금 게이트** — 서버 실효 프로바이더(운영자 설정 API · 없으면 로컬 `.env`)를 `scripts.scenario.preflight.external_planes` 하나로 판정한다. 외부 평면이면 실행 전에 사람의 `yes`(또는 `--yes`)를 받는다.
- **근거**: 시연 목적은 「웹에서 이어 갈 수 있는 실제 대화」라 격리 러너로는 성립하지 않는다. 판정 러너를 시연 요구로 넓히면 측정 계약(D-216 · D-241)이 흔들린다. 운영 식별자 비반출은 apm_bench 자리표 파일 규칙과 같다.
- **구현**: `scripts/demo/{__init__,__main__,catalog,client}.py` · `testdata/demo/{sessions.yaml,env.sandbox.yaml,env.closed.template.yaml}` · `tests/test_scripts/test_demo.py`(MockTransport 가짜 서버) · `docs/35_demo_script_guide.md` · `.gitignore`.
- **주의**: 실행기는 본체 서버의 체크포인트·이력에 실제 대화를 남긴다. 상태를 바꾸는 세션(G6-3 양식 기억 — 전역, G8-1 유사어 등록, G8-2 캐시 갱신)은 시연 뒤 정리가 필요하다(가이드 §7). 매뉴얼 동반 정책(D-255) 대상이 아니다 — 사용자·관리자 화면 기능이 아니라 개발·시연 보조 스크립트다.
- **관련**: D-216 · D-222 · D-241 · D-248 · D-255 · D-323(apm_bench 자리표) · `docs/35_demo_script_guide.md`
