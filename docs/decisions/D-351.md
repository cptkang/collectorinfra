## D-351. 노이즈 관제 결정 이력 — 「솔루션」·「존」 칸 + 솔루션 필터 · 출처는 판단 기록의 `db_id`를 레지스트리로 조회 시점에 푼다 (사용자 지시 2026-10-29 · D-247 · D-245 위)

- **결정일**: 2026-10-29 | **상태**: 확정 · 구현(브랜치 `improve_noise_canceling`) | **번호**: 등재 직전 `ls docs/decisions/` 최댓값 D-350 · 색인 끝 행 D-350 → D-351
- **배경(사용자 지시)**: *"결정 이력은 이 알람의 소스를 확인할 수 없다는 단점이 있음. 칼럼을 추가해서 어떤 소스로부터 온 알람인지, 어떤 존의 알람인지 표시"* → 필터는 *"db_id보다 상위 개념인 솔루션별(제니퍼, 폴스타, ...)"* · *"필터는 결정 이력만을 위한 내용"* · 서랍·세부 리스트의 존 표기 일치에 동의.
- **결정**:
  1. **출처는 새로 기록하지 않는다.** 판단 기록에 이미 있는 `db_id`(D-247 ③)를 **조회 시점에** 레지스트리(`config/db_registry.yaml`)로 푼다. 기록 형식·판정 6값은 비트 동일이다.
  2. **솔루션 = 레지스트리 `solutions[].code`.** DB 항목은 `family` → 그 family의 솔루션, APM 알람 `jennifer_<소스 id>`는 `alarm_source`(소스 표). 소스 표가 사라져도(폐쇄망 config 덮어쓰기 — 2026-10-13 사례) `jennifer`·`jennifer_*`는 `is_apm_db_id` 고정 규칙으로 APM에 넣는다(솔루션 유지 · 위치만 빈다). 못 풀면(`db_id` 기록 이전 판단 · 미등록 db_id) `unclassified`(「미분류」)로 모아 화면에서 사라지지 않게 한다.
  3. **위치(존 칸) = 존 약칭 + 사이트**(공동존 김포 · 공동존 여의도 · 은행존). APM은 소스 라벨에서 끝의 솔루션 이름을 떼어 존 약칭과 합친다(공동존 운영 · 공동존 개발/스테이징 · 은행존). 이름을 못 풀면 화면은 `db_id` 원문으로 폴백한다.
  4. **판정은 라우트 계층에서 주입한다.** 저장소(`noise_gate/infrastructure`)는 레지스트리를 모른다 — 라우트가 `solution_of`(db_id → 코드) 분류 함수를 넘기고(마스킹 `mask_fn`과 같은 방식), db_id당 1회만 부른다.
  5. **`GET /decisions` 가산 계약**: 행에 `solution`·`solution_label`·`location_label` · 인자 `solution`(빈 값 = 필터 없음 · 모르는 코드는 0건) · `facets.solutions`(**solution 필터만 뺀** 집합 · 0보다 큰 키만 — D-247 ⑤ 칩 규칙과 같음) · `solution_labels`(코드 → 표시 이름). `tiers`·`stages` 칩은 솔루션 필터를 반영한다(건수와 칩 합이 맞는다). `GET /decisions/{alarm_id}`(결정 추적)도 같은 출처 3키를 싣는다.
  6. **필터는 결정 이력 표에만 걸린다.** KPI·퍼널·추이·세부 리스트는 솔루션을 가리지 않는다(사용자 확정). 선택지는 조회마다 기간 안에 판단이 있는 솔루션 + 「미분류」로 다시 채우고, 고른 값은 0건이 돼도 남긴다. 다른 선택 상자처럼 「조회」·Enter로 반영한다.
  7. **표기 일치**: 결정 이력 표(8칸: 시각·알람·서버·솔루션·존·티어·결정 단계·사유) · 결정 추적 서랍(「솔루션」 줄 추가 · 「존」 줄 = `위치 (db_id)`) · 세부 리스트 「존」 칸이 같은 위치 이름을 쓴다. 표·리스트의 존 칸은 마우스를 올리면 `db_id`가 보인다.
  8. **플래그 없음** — 판정 무영향 읽기 전용 표시·필터이고 응답은 키 가산만이다(D-247 ③과 같은 예외 근거). 사용자·운영자 경로 공통(D-245 · 출처 라벨은 레지스트리 값이라 마스킹 대상 아님).
- **근거**: D-247(판단 기록 최상위 `db_id` · facets 규칙 · 세부 리스트 공용 패널) · D-245(핸들러 공유) · D-287 ④(제니퍼 소스 ↔ 존 정본은 레지스트리) · D-139(`noise_gate → src`는 routing 최소 — `server_identity`가 이미 레지스트리를 읽는다) · `docs/18` 2026-10-13 폐쇄망 config 덮어쓰기.
- **대안(기각)**: 기록 시점에 솔루션·위치를 레코드에 저장(옛 판단은 여전히 못 풀고, 레지스트리 정정이 과거 행에 반영되지 않는다) · `db_id` 단위 필터(사용자가 솔루션 단위를 원함 — 위치는 칸으로 읽는다) · 검색어에 출처 포함(선택이 명시적이지 않다) · 화면 전체(KPI·퍼널) 솔루션 필터(집계 경로 전부 수정 — 사용자 범위 밖).
