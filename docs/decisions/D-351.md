## D-351. 조사 결과 표시 3단 — 관제 요원 첫 화면(원인 영역·확실성) · 담당자 전달문 · 펼쳐 보는 근거 (plans/199)

- **결정일**: 2026-10-29 | **상태**: 확정 · 구현(`plans/199` W0~W6 · 2026-10-30 완료) · **플래그 코드 기본 on**(부기 2 · 사용자 결정 · 내부망 확인 생략) | **번호**: 등재 직전 `ls docs/decisions/` 최댓값 D-350 확인
- **배경**: 사용자 제기 *"RCA의 조사 결과(서술보기)가 너무 복잡한 디스크립션으로 제공되어 모두 읽어봐야만 알 수 있다. 핵심적인 내용을 요약하여 보거나 강조 또는 일목요연하게 표나 그림으로 제공되거나 해야 된다."* — 상세형에서 결론(1순위 원인·지금 할 일)이 7번째 블록에 묻히고, 같은 결론이 4~5곳에 반복되며, 엔진 비교 [서술 보기]는 HolmesGPT 마크다운 원문을 평문으로 보인다(`plans/199` §1).
- **결정**:
  ① 조사 결과 화면의 주 사용자는 **관제 요원**(결과를 보고 담당자에게 넘김)이다. 담당자도 일반 사용자 계정이라 계정으로 화면을 나누지 않는다 — **① 한눈에 보기(펼침) → ② 근거 요약(접힘) → ③ 상세(접힘)** 3단이고 누구나 펼친다. 펼침 선택은 브라우저 저장소에 편의로만 기억한다. 노출 범위는 서버가 정한다 — **D-325 ③ 개정 없음**. 역할 모델(`user`·`admin`) 불변.
  ② 첫 줄은 **원인 영역**(`engine_agreement.playbook.layer` → `unknown`이면 `holmesgpt.layers[0]`(추정) → 없으면 「미확정」)과 **확실성 배지**(확정·추정·미확정 — `plans/199` §3.2 결정적 규칙)다. 화면은 enum → 문구 표만 가지며 계층 판정 정본은 sre_agent `engine_agreement.py`에 그대로 둔다. 모르는 enum은 원문 그대로 보인다.
  ③ 요약·전달문은 브리핑에 이미 있는 구조화 필드의 **결정적 조립**이다 — 새 LLM 호출·요약 프롬프트 없음(D-035). 판정·가설 순위·티어·통보·저장 스키마 불변.
  ④ **전달문** = 고정 양식 미리보기 + 클립보드 복사. 시스템이 메신저·문자로 직접 보내지 않는다. 사용자 뷰는 서버가 가린 값 그대로 실리고, 운영자 뷰에서 복사하면 원문이 나가므로 운영자 화면 복사 버튼에 「원문 포함」 표지를 단다.
  ⑤ [서술 보기]는 원인·근거·대응·한계 4줄 요약을 먼저 보이고, 원문은 접어 둔 채 **escape 먼저 · 화이트리스트 변환 나중**의 내부 마크다운 렌더(제목·목록·굵게·인라인 코드·파이프 표 — 링크·이미지·HTML 미변환)로 정리한다. HolmesGPT 답변 형식을 프롬프트로 고정하지 않는다.
  ⑥ 장애 진단 진행 중 「실행 기록」은 전환 탭 대신 맨 아래 접힘 섹션으로 둔다 — D-341 부기 11 **G-50 개정**(D-341 부기 22).
  ⑦ 플래그 `NOISE_INVESTIGATION_SUMMARY_VIEW_ENABLED`(`cfg.noise_gate.investigation_summary_view_enabled` · 기본 off = 비트 동일 · 기능 조회 `investigation_summary_view_enabled` 가산 필드 1개). 내부망 확인 뒤 **코드 기본값**을 on으로 바꾼다(이 결정 부기).
  ⑧ 범위 밖: 담당자 이름 조회(ITAM 등 — 모델 `owner` 자리만) · 전달문 직접 발송 · 담당자 역할·계정 구분 · 가설 신뢰도 점수(198 I-3 소유 — 가설 표 자리만).
- **근거**: `plans/199` §0.1·§8 사용자 인터뷰(2026-10-29 · Q1~Q6 확정).
- **구현**: `plans/199` W0~W5 — 플래그 `src/config/alarm.py` · 기능 조회 `src/api/routes/alarm.py`·`alarm_schemas.py` · 화면 `src/static/js/briefing-view.js`(`summaryModel`·`summaryCardHtml`·`handoffText`·`isRawView`·`renderPlaybookTiers`·`renderMarkdownSafe`·`deepNarrativeHtml`·`TERM_*`)·`diagnosis-view.js`·`app.js`·`noise.js`·`style.css` · 매뉴얼 U-74·U-70·A-87 · 전 파일은 계획서 머리 「회귀 대상 파일」, 이탈은 계획서 §10.
