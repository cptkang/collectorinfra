## D-324. sre_agent 조사 품질 벤치마크 계약 — **정답을 구성으로 아는 합성 장애 세계(가짜 MCP 서버) · 실제 조사 경로 · 결정적 채점 + 외부망 Claude Code 검토 · 홀드아웃으로만 처분 · 측정은 내부망 사내 vLLM · 계측 가산 키 상시** (`plans/151`)

- **결정일**: 2026-10-12 | **상태**: **확정(계획 · 코드 0)** | **번호**: 2026-10-12 색인 예약 행 → 같은 날 본문 등재(등재 직전 `ls docs/decisions/` 최댓값 D-323 · 색인 끝 행 D-324 예약 확인)
- **배경**: 사용자 요청(2026-10-12) *"sre_agent를 통해 장애 분석을 하는 기능에 대해 벤치마크 테스트를 통해 개선포인트를 개측하여 개선을 진행하려고 한다."* 실측(`3c4adab`): 원인 정답이 붙은 조사 데이터 0건 · 미완주 조사가 `done`으로 기록(`diagnosis.py:223`의 `incomplete`를 읽는 곳 0) · 감사에 지연·step·도구 호출 수·모델명 없음 · 질문 고정 템플릿 1종 · 인용 검증은 마커 문자열만 · 품질 기능 대부분 기본 off. 게이트 G-1~G-8은 같은 날 사용자 인터뷰로 확정.
- **결정**:
  ① **장애 세계 = 가짜 세계 MCP 서버**(G-1 (a)) — 실 `mcp_server`(+`apm_gateway`)와 같은 도구 이름·인자 스키마로 세계별 응답을 합성한다. 스키마 정본은 실 서버 `list_tools` 스냅샷(MCP 프로토콜로 받음 · import 0 · D-139). 정답(`root_entity`·`layer`·`kind` — `plans/101` 라벨 스키마)은 세계 YAML에 있고, 정답 원인 문구를 알람·질문·지침에 넣지 않는다(린트 · KL-3).
  ② **실제 조사 경로** — 벤치는 `sre_investigate_alarm` submit/poll로 들어간다(사전수집·지침·판정·브리핑 전부 경유). HolmesGPT를 직접 부르지 않는다.
  ③ **결정적 채점 + 외부망 Claude Code 검토**(G-5) — 원인 적중(RC@1·RC@3) · 증거 폐포(ECR) · 환각(HALLU) · 유인(DIST) · 기권(ABST) · 완주 · 비용 · 일관성(Maj@k)과 실패 유형 12종을 규칙으로 판정한다. LLM 심판은 쓰지 않는다. 반출 로그를 외부망 Claude Code가 검토해 **채점 교정안(→ `--rejudge`) · 실패 원인 진단·개선 후보 · 개선 코드(플래그 뒤)** 를 낸다. 절차 정본은 `plans/151` §6.6(스킬화하지 않음).
  ④ **개발/홀드아웃 분리**(G-7 · G-8) — 개발 16 · 홀드아웃 8 · 반복 3회. 처분은 홀드아웃에서만, A/A 잡음폭과 가드 지표(완주율·HALLU·DIST·지연 p90 +50% 이내)로 내리고 D-238 처분 어휘(`채택 권고`·`기각`·`판정 불가`)를 쓴다. 외부망 검토는 채점 교정에만 홀드아웃 원문을 보고, 진단·개선 코드는 개발셋 원문만 본다.
  ⑤ **측정 = 내부망 사내 vLLM 회차**(G-4 · G-7) — 1회차 A/A 기준선, 이후 회차는 대조군 + 실험군. 외부망 로컬 MLX는 하네스 확인용 대표 3세계 × 1회와 개선 코드의 대표 1~2세계 × 1회만이며 점수를 처분에 쓰지 않는다. FabriX는 측정 대상이 아니다. 과금 평면(`gemini/…`·`anthropic/…`·공용 API 호스트)은 사전 점검이 거부한다(D-127).
  ⑥ **반출 묶음** — 브리핑 전문·도구 호출 순서·인자·세계 서버 응답·계측 키·점수를 담고, 가리는 것은 내부 주소·실행 계정·서버 호스트명·내부 경로뿐이다. 가린 뒤 잔존 검사에 걸리면 묶음을 만들지 않는다(D-301 누출 관문 준용). 세계가 합성이라 운영 데이터는 없다.
  ⑦ **계측 가산 키 상시**(G-2 (a) · G-3 (a)) — 조사 잡·`done` 감사에 `incomplete`·`elapsed_s`·`prefetch_s`·`steps`(얻을 수 있을 때)·`tool_calls_n`·`model`·`max_steps`·도구 기록 요약을 플래그 없이 더한다(동작 무변경). 미완주는 `status=done`을 유지하고 `incomplete:true`를 더한다 — D-123 상태 어휘 불변.
  ⑧ **개선 하나 = 플래그 하나 = 실험군 하나** — 신규 동작은 기본 off(비트 동일). `채택 권고`가 나오면 이 결정에 부기하고 기본값 변경을 사용자에게 제안한다.
  ⑨ **순서**(G-6 (a)) — 하네스는 `plans/150`과 병행하고, 내부망 기준선은 `plans/150` W5(sre_agent 질문·지침·사전수집 변경) 랜딩 뒤에 잰다.
- **근거**: 결정적=판단 · LLM=서술(D-035) · 관측 0 = 판정 불가(D-219) · 처분 어휘(D-238) · 과금 게이트(D-127 · D-240) · 지연 결론은 내부망 · 벤치 과적합 방지(홀드아웃) · 운영 리플레이 평가와 채점기 공유(`plans/101` P-24).
