## D-331. 품질 게이트 조정 — arch_check 「노드 간 직접 의존」 경고를 노드 패키지 간으로 한정 · 설정 `getattr` 폴백 린트 CI 게이트 신설

- **결정일**: 2026-10-14 | **상태**: 확정 · 구현 전(`plans/166` W1)
- **배경**: `plans/166` 분석(SHA `7ba5c96`)에서 두 게이트 공백이 실측됐다.
  - `scripts/arch_check.py:231-243`은 application 계층 안의 **모든** 모듈 간 import를 「노드 간 직접 의존 금지(그래프 라우팅으로 해결)」 경고로 낸다. 경고 117건 중 112건이 이 규칙이고, 그중 실제 노드 패키지 사이(`src.nodes.*`↔`src.nodes.*`)는 38건뿐이다. 나머지 74건은 `db_adapters/`·`semantic/`·`tools/` 내부나 노드→비노드 헬퍼 import라 그래프 간선으로 풀 대상이 아니다. 그래서 노드 패키지에 있는 순수 헬퍼를 비노드 모듈로 옮겨도 경고 수가 줄지 않아, 게이트가 개선을 측정하지 못한다.
  - 설정 필드 기본값과 **다른** 기본값을 쓰는 `getattr(cfg…, "필드", 기본)`이 약 80곳 있다. 예: `zone_group_exclusive`는 필드 `False`인데 폴백 `True`가 11곳, `trace_enabled`는 `False`↔`True`, `prompt_token_budget`은 `0`↔`90000`. 평시에는 `AppConfig`가 값을 채워 무해하지만 SimpleNamespace 테스트 설정이나 필드명 오타에서는 반대 방향 기본값으로 조용히 동작한다(Known Mistakes 2026-09-17 — `getattr`가 속성명 오류를 삼킴).
- **결정**:
  ① **arch_check 경고 범위 한정** — application→application 「노드 간 직접 의존」 경고는 **양쪽이 모두 노드 패키지일 때만** 낸다: `src.nodes.*`↔`src.nodes.*`, `noise_gate.application.nodes.*`↔같은 패키지. 경고 문구는 「순수 헬퍼는 비노드 application 모듈로 옮긴다」로 바꾼다. 다른 규칙(계층 방향 error · orchestration/interface→prompts 경고)은 그대로 둔다. 적용 직후 경고는 117 → **43**(노드↔노드 38 + prompts 직접 참조 5 · 2026-10-14 실측)이 되고, 이 값이 새 기준선이다.
  ② **설정 폴백 린트 신설 · CI 게이트** — `scripts/config_fallback_check.py`(이름은 구현 시 확정 가능)는 `getattr(<설정 객체>, "필드", 기본)`의 기본값을 `src/config.py` 필드 기본값과 AST로 대조해, 다르면 위반으로 센다. 판정할 수 없는 것(동적 이름·설정이 아닌 객체)은 건너뛰고 수만 보고한다. 처음에는 보고 모드로 현재 수를 기록하고, `plans/166` X1 치환으로 0이 되면 `--ci`(위반 시 종료 코드 1)로 바꿔 `regress.py` 정적 게이트에 넣는다. 존재하는 필드는 `cfg.<그룹>.<필드>`로 직접 접근하는 것이 원칙이다(오타는 `AttributeError`로 드러난다).
- **근거**: ① 게이트는 목표 구조(노드는 노드를 직접 부르지 않는다)를 재야 한다. 노드가 아닌 application 모듈 사이 import는 D-089(조립기는 어댑터 모듈 직접 import 허용)·`semantic/`·`tools/` 재노출 설계상 정상이다. ② 폴백 사본은 SSOT 위반이다. 기본값을 바꿀 때 grep으로 찾을 수 없고, 보고만 하는 린트로는 재유입을 막지 못한다. ③ 테스트 설정은 실 `AppConfig`에 검증 대상 필드를 명시해 쓴다(CLAUDE.md pydantic-settings 원칙). SimpleNamespace 때문에 깨지는 테스트는 그 방향으로 고친다(`plans/166` U-7).
- **구현**: `plans/166` W1 — `scripts/arch_check.py` 규칙 수정과 `tests/test_orchestration/test_arch.py` 규칙 단언, 린트 스크립트 신설과 `scripts/regress.py` 정적 게이트 편입. 공유 파일이므로 team-lead가 통합한다.
- **주의**: ① ①로 경고 수가 줄어든 것을 「구조가 개선됐다」로 보고하지 않는다. 개선은 43에서 줄어든 만큼만 센다(N3 이동 뒤 목표 17 이하). ② `noise_gate/application/nodes/alarm_context_enricher.py:35` → `server_identity` 경고는 대상이 노드가 아니어서 ①로 사라진다. 그래도 `plans/166` G4 처방(`is_apm_source` → `noise_gate/domain`)은 그대로 한다. ③ 린트는 `src/config.py` 필드에만 대조한다. `mcp_server`·`apm_gateway`·`sre_agent`의 자체 설정은 대상이 아니다.
