## D-262. 질의 결과·다운로드 API 소유자 인가 · CSV 마스킹을 화면과 같게 · 파일 다운로드 감사 (사용자 지시 2026-09-27 · `plans/116` §8-1·§11.8.3 ③④ · D-069 정합 · D-248 ③ 유지)

- **결정일**: 2026-09-27 | **상태**: 확정·구현
- **결함**: 결과·매핑 보고서·생성 파일·CSV 조회와 매핑 피드백 API가 무인증이라 query_id만 알면 남의 결과를 받거나 전역 유사어에 반영할 수 있었다. 첨부 원본은 로그인만 확인했다. CSV는 화면(`result_organizer`의 `DataMasker`)과 달리 원본 행을 그대로 냈다.
- **결정**: 여섯 라우트에 `require_user` + `_owned_result` — 결과 저장 6곳이 남긴 소유자(`owner_sub`)와 같은 사용자 또는 DB 실시간 역할 admin만 통과, 그 밖 403 「이 결과는 질의한 사용자만 받을 수 있습니다.」, 소유자 기록 없는 결과는 내주지 않는다. `AUTH_ENABLED=false`는 종전대로. CSV는 **내보낼 때만** 같은 `DataMasker`로 가리고 저장된 `query_results`는 전량·원래 순서 유지(D-047·G-4). 성공한 다운로드 4종은 `log_file_download`로 감사. 화면은 헤더 인증으로 받아 Blob 저장(토큰 URL 미사용 · 401이면 재로그인 · `app.js?v=13`).
- **대안(기각)**: 쿠키 인증으로 링크 유지(헤더 원칙·교차 사이트 GET) · 쿼리 토큰(접근 로그) · 404로 존재 숨김(정상 사용자가 원인 모름) · 저장 시점 마스킹(지점 분산·원본 보존과 충돌).
- **검증**: `tests/test_api/test_query_result_access.py` 31건(수정 전 무인증·타인 요청 200 재현) · headless 화면 14항목.
- **잔여(결정 필요 포함)**: 인증 꺼진 설치에서는 여전히 query_id만으로 받는다(D-248 `X-Client-Id` 적용 여부 미정) · 관리자가 타인의 DRM 해제 원본을 받을 수 있다(D-156 후속1 관점 검토) · 처리 현황 패널 미리보기 10행 원본 노출(D-249 원칙과 불일치) · 한글 첨부 파일명 원본 받기 500(latin-1 헤더) · 운영자 토큰으로는 이 API 사용 불가(401).

- **부기(2026-09-27 · 잔여 해소 — 「권고대로 진행하라」)**: ① **첨부 원본은 올린 본인 전용** — `GET /query/{id}/attachment`만 `_owned_result(allow_admin=False)`로 좁혀 관리자도 남의 원본은 403 「원본 첨부 파일은 올린 사용자만 받을 수 있습니다.」(저장본이 DRM 해제 평문이라 관리자 허용은 D-156 후속1의 「관리자 복호화 다운로드 — 승인 전 범위 밖」과 같은 효과였다). 결과·CSV·생성 파일·매핑 보고서·피드백은 종전대로 관리자 허용. ② **다운로드 헤더 RFC 6266/5987** — 공용 `_attachment_disposition`을 네 라우트가 쓴다(비ASCII면 `filename*=UTF-8''…` + ASCII 대체, 순수 ASCII는 종전 바이트 그대로). 한글 원본·생성 파일명 500 해소 · 화면은 `filename*`을 먼저 읽는다(`app.js?v=14`). ③ **처리 현황 미리보기 마스킹** — `_extract_node_progress(..., security=)`가 `preview_rows` 10행을 같은 `DataMasker`로 가린다(D-249 원칙 · 저장 원본 불변). ④ **인증 꺼진 설치**는 코드로 막지 않는다 — 익명 모드는 원래 인증이 없는 설정이라, 관리자 매뉴얼 A-01에 「보호가 모두 꺼진다 · 운영은 반드시 `AUTH_ENABLED=true`」를 명시했다(운영 `.env`의 실제 값은 이 세션에서 확인하지 못했다). 검증: `tests/test_api/test_query_result_access.py` 31→46건(수정 전 16 실패). 잔여: 운영자 토큰으로는 이 API 불가(401) · 관리자 원본 받기가 필요하면 정보보호부 승인 후 별도 결정 · `db_structure.py` 차이 보고서 헤더는 헬퍼 미사용(ASCII 가정).
