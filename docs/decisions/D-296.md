- **배경**: `plans/134` v1.0(제니퍼 질문 전량 지원)이 올린 게이트 중 API 허용 범위(G-2·G-3·G-4·G-5)와 조회 범위(G-6·G-8)에 대한 사용자 지시다. 「모든 API」의 범위가 보안 경계를 바꾸므로 확인 질문 2건을 거쳤다 — ① 「조회 API 전부(민감·쓰기 차단)」 · 「민감 조회 API까지」 · 「쓰기·제어 API까지 전부」 중 **「민감 조회 API까지」** ② 「한도 유지·끝까지 조회」 · 「미리 모아 두기」 · 「보호 한도도 올림」 중 **「보호 한도도 올림」**.
- **결정**:
  ① **허용 = 제니퍼 Open API의 읽기(GET) 경로 전부** — 스펙 5.6.4(v1·v2·restapi)와 v2 매뉴얼의 GET 경로. 새로 여는 것: 서비스·업무 단위(`/api/realtime/domain` · `/api/dbmetrics/domain` · `/api/realtime/business` · `/api/dbmetrics/business` — `/api/business`는 D-290 ④) · `/api/transaction/guid` · 기존 경로의 스펙 선언 선택 키 전부 · **민감 조회**(`/api/auth/userlist` · `/restapi/users` · `/restapi/user/{id}` · `/api-v2/environment-variable/{d}` · `/api-v2/loaded-class/{d}/{i}` · `/api-v2/active-service/detail/{d}/{txid}`) · **관리 조회**(`/api-v2/manage/rule/event/{error|metric|compare}/…` · `/api-v2/manage/rule/active-service-color-range-boundary` · `/api-v2/manage/instance?processId=&hostname=` · `/api-v2/manage/db/path/{d}` · `/api-v2/manage/data-server/{domains|resource|system-property-config}`). 데이터가 없는 시험 경로(`/api-v2/test-response/json` · `/api-v2/auth-test`)는 넣지 않는다.
  ② **쓰기·제어는 계속 막는다** — GET 외 메서드 전부 거부(D-003 · D-195 ① 그대로). 1차 통제 방식(메서드 + 경로 템플릿 정확 일치 · 그 밖 거부 · 쿼리 `token` 거부 · 리다이렉트 비추종 · 코드 상수)은 그대로이고 **목록만 넓힌다**. v1 조회 API의 POST 변형과 `.xml` 변형은 같은 데이터의 다른 표현이라 넣지 않는다(GET JSON만 — 잃는 데이터 없음).
  ③ **자격증명 값은 어떤 경로로도 내보내지 않는다(불변)** — `/restapi/users`·`/restapi/user/{id}` 응답의 `password` 필드는 게이트웨이가 버린다 · 환경변수·시스템 속성 중 비밀 패턴 키(`PASSWORD`·`SECRET`·`TOKEN`·`KEY`·`CREDENTIAL` 등 — 정확한 목록은 `plans/134`)의 값은 가린다. 개인정보(이메일·휴대폰·`userId`·SQL 바인드 값·HTTP query)를 누가 묻고 원값으로 보게 할지는 **G-11(사용자 확정 대기)** — 확정 전에는 현행 마스킹 규칙(`apm_gateway/apm_gateway/application/masking.py`)을 그대로 적용한다. D-120(운영 데이터 외부 LLM 금지)과 FabriX PII 필터 대응은 그대로다.
  ④ **조회 범위의 자체 상한을 없앤다** — 기간·대상·건수 상한(채팅 보기 창 10분·24시간 · 하루 넘게 지난 기간 미조회 · 인스턴스 목록 200 · 추세 인스턴스 2개·지표 3종 · 대상 상한 10 · `n` ≤ 20 · 이벤트 50건 · 순위 상위 K)을 걷어낸다. 남는 한계는 **제니퍼 쪽 사실**뿐이다 — 보존 기간 · X-View 1분 창(게이트웨이가 나눠 부른다) · `/api/status/*` 시 단위 · 소스 변경 25시간(나눠 부른다) · 로드된 클래스 6만 개 · 호출 속도 상한(⑤). 결과가 크면 채팅에는 요약과 상위 행을, 전체 행은 결과 다운로드(CSV)로 준다 — 조회 범위를 줄이지 않는다. 조사(`sre_agent`)의 조사당 프로파일 호출 상한(5회)·정체 가드는 사용자 조회 범위가 아니라 LLM 반복 호출 방지라 유지한다.
  ⑤ **호출 속도 상한을 올린다** — `JENNIFER_RATE_LIMIT_PER_SEC`(소스별 `JENNIFER_<ID>_RATE_LIMIT_PER_SEC`). 값은 제니퍼 운영 조직 협의값(`plans/87` U-7 뷰 서버 부하 상한 · 토큰 사용량 한도)으로 정한다(**G-12**) — 정해지면 `.env`가 아니라 코드 기본값으로 고정하고, 협의 전 기본값은 현행 5다. 큰 조회는 소스·도메인 병렬 호출과 진행 표시로 끝까지 수행하고, 채팅 대기 상한은 조회 규모에 맞춘다(침묵 타임아웃 금지 — `plans/134` M-10).
