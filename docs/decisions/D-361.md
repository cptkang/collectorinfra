## D-361. 조사 답변 언어 지침 — HolmesGPT 결론은 항상 한국어

- **결정일**: 2026-11-03
- **상태**: 확정 · 구현 완료(`sre_agent/sre_agent/diagnosis.py`) · 폐쇄망 확인 대기
- **결정**:
  ① `DiagnosisAgent.ask()`가 넘기는 `system_prompt_additions` **맨 끝**에 응답 언어 지침(`ANSWER_LANGUAGE_NOTE`)을 항상 붙인다 — 부하 가드(`LOAD_GUARD_NOTE`)와 같은 상시 주입이다. 결론·원인 가설·근거·권고·추가 확인 항목은 한국어로 쓰고, 도구 이름·명령·메트릭 이름·호스트명 등 식별자와 로그·오류 원문 인용은 번역하지 않는다.
  ② 지침이 이미 들어 있으면 다시 붙이지 않는다. 기능 플래그는 두지 않는다(사용자 노출 문구 일관성 결함 교정 · 도구 호출·판정 로직 불변).
- **근거**: 폐쇄망 보고(2026-11-03) — 심층 조사(`holmesgpt` 가설)의 결론이 가끔 영어로 나온다. 실측: holmes 기본 시스템 프롬프트는 영어이고, 조사 경로(`build_guidance` → `ask()`)에 응답 언어 지시가 0건이었다(`playbook_prompts.py`의 소견·종합 프롬프트에만 「한국어 평서문」 지시가 있음). 영문 도구 출력이 길게 쌓이면 모델이 영어로 결론을 쓴다. 답변을 영문 머리말로 파싱하는 코드는 없어 지시 추가가 하류를 깨지 않는다.
- **구현**: `sre_agent/sre_agent/diagnosis.py` — `ANSWER_LANGUAGE_NOTE` · `_with_answer_language_note`(`ask()`에서 `_with_load_guard_note` 결과에 적용 — HolmesGPT 진입점은 이 한 곳). 테스트 `sre_agent/tests/test_answer_language_note.py`.
- **주의**: 프롬프트 지시라 결정적 보장은 아니다. 폐쇄망에서 계속 영어가 섞이면 후속으로 ① 질문(유저 메시지) 끝 한 줄 지시 ② 답변 언어 감지 후 한국어 재작성 1회(LLM 1회 추가) 중에서 고른다.
- **관련**: D-341(조사 플레이북) · D-197(조사 지침 조립)
