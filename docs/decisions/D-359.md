  ③ **상한 곱셈 금지** — 조사 실행을 자식 프로세스로 나눠도 전역 도구·LLM 동시 상한은 부모가 쥐는 공유 세마포어로 서비스 전체 합을 지킨다(spawn · D-347 ③ · D-356 ④ · D-357 ①과 같은 방향). 조회 대상 보호 상한(D-347 ③)은 바꾸지 않는다.
  ④ **알람 워커는 다중 프로세스를 택하지 않는다** — 판정 상태가 프로세스 메모리·도착 순서에 의존한다. 대신 프로세스 안에서 게이트 사전 판정은 직렬, 그래프 실행 이후는 동시 N건(충돌 키 순서 보장) · `ALARM_WORKER_MAX_CONCURRENCY` 기본 1 = 현행과 비트 동일.
  ⑤ **본체 uvicorn 다중 워커(M-6)는 범위 밖**(사용자 확인).
  ⑥ 신규 플래그는 전부 기본 off(또는 1) = 현행과 비트 동일(D-162).

- **부기 1 (2026-11-02 · 사용자 결정 — 메인 세션 경유)**:
  ① **트랙 C M-3 = 「최근 구간만 읽기 + 판정 파일 회전」 둘 다**. 관제 집계(`aggregate`·`meta_alerts`)는 파일 끝에서 거꾸로 읽다가 집계 창 밖에서 멈춘다. 판정 파일은 크기·날짜 기준으로 회전하고 **회전 조각은 지우지 않고 보관**한다(감사 기록 — 삭제·보존 기한은 범위 밖). 판정 파일을 읽는 곳은 모두 조각을 가로질러 읽는다. 플래그 기본 off = 현행과 비트 동일 · 기본 on 여부는 사용자에게 따로 묻는다.
