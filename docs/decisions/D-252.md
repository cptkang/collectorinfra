## D-252. 사용자·관리자 매뉴얼 — **정적 HTML 2권을 메인 화면에서 연다 · 캡처는 녹화 재생 위에서 스크립트가 찍는다 · "모든 기능"은 manifest 와 가드 테스트로 약속한다** (`plans/116` · 사용자 확정 2026-09-23 · G-1~G-6 권고안)

- **결정일**: 2026-09-23 | **상태**: 확정 (구현 · `plans/116`) | **번호**: **D-252**
- **배경**: 사용자·관리자 매뉴얼이 없었다(`src/static`에 매뉴얼 HTML 0건). 요구: 캡처 화면과 자세한 설명이 든 HTML, 제공 기능 전부, 두 권 분리, 메인 화면에서 바로 선택. 추가 요구: 사용자 매뉴얼은 프롬프트 사례와 실행 결과 샘플로 설명.
- **결정**:
  - ① **산출물** — `src/static/manual/{user,admin}.html`(자기완결 · 외부 리소스 0 · 라이트/다크 · 인쇄) + 라우트 `/manual/user`·`/manual/admin`(다른 HTML 화면과 같이 서버 인증 없음 — G-2) + 메인 머리글 링크 2개(관리자 매뉴얼은 Admin 링크와 **같은 분기**에서 노출 · 새 탭 D-248) + 보조 진입 4곳(로그인·관리자 대시보드·노이즈 화면 2).
  - ② **"모든 기능" = manifest** — `scripts/manual/features.yaml`(사용자 45 · 관리자 61)가 정본이고 `tests/test_manual`이 강제한다: 항목마다 절·5칸(무엇·사용 방법·화면 요소·주의·관련) · 캡처 실존 · 화면 앵커 실존 · **역방향 감시**(화면의 버튼 id·탭 값 중 manifest 미등재 0 — 새 버튼이 생기면 테스트가 실패한다) · 외부 URL 0 · 초안 빌드 금지 · 샘플 민감 문자열 0.
  - ③ **캡처는 녹화 재생 위에서** — 실 파이프라인(샌드박스 + 로컬 MLX 두 평면, D-240)을 한 번 녹화(`RecordingGraph`)하고, 캡처 서버는 그래프를 빌드하지 않고 녹화를 재생한다(`ReplayGraph` · LLM 호출 0). 라우트가 재생 그래프를 구별하지 못하므로 결과 저장·다운로드·이력·역질문 패널이 실경로로 돈다. 알람은 워커가 발행한 pub/sub 이벤트를 녹화해 재발행한다.
  - ④ **격리 스냅샷** — 관리자 설정 화면이 **프로젝트 루트의 `.env`를 고정 경로로** 읽으므로(`admin.py` `_ENV_FILE`) 저장소에서 띄우면 운영 설정이 찍힌다. 작업 트리를 `build/manual_capture/app*`로 복사하고 캡처 전용 `.env`만 둔다(`.encenv` 없음). 스냅샷 생성이 핵심 키 해석값(인증 DB·두 평면·포트)을 **자동 검증**한다(docs/18 2026-09-23 재발 방지).
  - ⑤ **사례 결과는 지어내지 않는다** — 샘플마다 샌드박스 독립 SQL 로 대조해 판정(`ok`·`partly`·`wrong`)을 샘플 파일에 남기고, `wrong` 은 싣지 않는다(문장을 바꿔 재녹화). `partly`(표는 맞고 요약 문장에 흠)는 본문 「포인트」가 흠을 밝힌다. 매뉴얼 빌드는 입력·결과 표를 샘플에서만 가져온다(손으로 옮기지 않는다).
  - ⑥ **범위** — 화면 없는 기능(채팅 명령 3종 · 관리 API)도 싣는다(G-3). 운영 절차는 요약 + 기준 문서 링크(G-4 — 정본 이중화 금지). 캡처 이미지는 커밋한다(G-1).
- **근거**: 사람이 찍은 캡처는 재생성할 수 없어 UI 변경과 함께 낡는다. 문장으로 "모든 기능"을 약속하면 누락을 알 방법이 없다. 녹화 없이 모의 응답을 쓰면 매뉴얼 결과가 실제 모양과 달라진다.
- **대안**: 사람이 수동 캡처(재생성 불가 — 기각) · 모의 응답 수작업(실제와 어긋남 — 제어 화면에만 허용) · 운영 결과 캡처(호스트·IP 노출 — 기각) · 캡처 시 실 LLM 호출(비결정·느림 — 녹화 1회로 대체).
- **주의**: ①결정성은 **내용**(응답·표) 한정이다 — 시각 표시는 캡처 시점을 따른다(결정 기록을 현재로 옮기므로 브라우저 시계를 고정하면 상대 시각이 어긋난다). ②플레이라이트는 루트 venv 에 없다 — `uv run --with playwright`로만 쓰고 브라우저는 캐시(`chromium-1208`)를 쓴다(다운로드하지 않는다). ③UI 를 바꾸면 가드가 실패한다 — 매뉴얼 갱신이 UI 변경 작업의 일부가 된다(`python -m scripts.manual.run_capture`).
- **관련**: D-038(사용법 버튼 — 병존) · D-069 · D-127·D-240 · D-178 · D-245 · D-248.

- **부기(2026-09-27 · 사용자 지시 — 위 부기 재개정)**: 소제목·항목을 통째로 접던 방식을 다시 바꾼다 — **일반 설명은 본문에 보이고 자세한 설명만 항목마다 「자세히」로 연다.** 칸 이름은 「상세 설명」, 칸 머리에 소제목별 항목 바로가기 링크, 소제목은 접지 않는 제목, 항목은 제목 + 첫 문단(또는 첫 글머리표)이 보이고 나머지가 접힌다. 원천 형식(`####`·`#####`)은 그대로이고 빌드가 나눈다. 가드: 항목마다 보이는 일반 설명 필수(`plans/116` §11.7).
