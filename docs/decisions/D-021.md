## D-021. Gemini API 프로바이더 추가 + 민감 키 분리 (Plan 28)
- **결정일**: 2026-03-25 | **상태**: 구현 완료 | **이전 결정**: D-006 확장
- **결정**: Ollama 환각 검증 목적으로 Google Gemini를 3번째 LLM 프로바이더 추가. API 키 등 민감정보를 `.encenv` 파일로 `.env`와 분리 관리.
