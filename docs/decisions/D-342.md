## D-342. sre_agent 조사 — 폴스타 MCP 툴셋이 끝내 연결 안 되면 LLM 조사를 생략하고 「조사 불가」 브리핑으로 종결

- **결정일**: 2026-10-19 | **상태**: 확정 · 구현(`plans/188` W3 · W4 부기 2026-10-19 · 커밋 없음)
- **결정**: 조사 직전 holmes 툴셋 상태를 보고, 캐시된 조사 에이전트에 FAILED MCP 툴셋이 있으면 에이전트를 **1회 다시 만든다**(정상이면 재생성 0회). 다시 만든 뒤에도 `polestar` MCP 툴셋이 FAILED면 **LLM을 부르지 않고** 「조사 불가 — 관측 도구 연결 실패(이름: 사유)」 결과로 종결한다 — 잡 `status=done`(D-123 상태 어휘 불변) · 브리핑 요약 `[미결] ` 접두 · 같은 문구 1줄을 limitations에. **APM 툴셋만 FAILED**면 생략하지 않고 기존 APM 미가용 폴백(미연결 한계)을 따르며, 조사 지침의 도구 이름은 실제 로드된 도구로 걸러 넣는다. `sre_health.polestar_mcp_reachable`은 마지막 조사 직전 검사 결과(true/false/null — 헬스 호출마다 프로브하지 않음)이고 false면 선택 키 `polestar_mcp_error`를 더한다(CONTRACT_VERSION 불변).
- **근거**: 폐쇄망 브리핑(2026-10-19)이 요약·타임라인·원인 가설을 도구 오류 문구로 채웠다. 원격 프로파일은 bash가 꺼져 있어(D-233) 폴스타 MCP가 없으면 남는 데이터 도구가 사실상 없다 — LLM 조사를 진행하면(B안) 비용만 쓰고 근거 없는 서술이 나온다. A안은 LLM 비용 0 · 오류 문구가 가설이 되는 일 원천 차단 · 운영자가 즉시 연결 문제로 인지. holmes 0.36.0은 MCP 툴셋을 `create_toolcalling_llm` 시점에 즉시 검사하고 FAILED를 같은 인스턴스 안에서 재검사하지 않으므로(실측) 재생성이 회복 경로다. 사용자 확정 2026-10-19(Q1=A).
- **구현**: `sre_agent/sre_agent/diagnosis.py`(`DiagnosisAgent.mcp_unavailable`·`tool_names` · `DiagnosisResult.tools_unavailable` · `tools_unavailable_result`) · `interface/mcp_service.py`(`_default_diagnose_fn` 락·재생성 1회·단락 · `ToolsetCheck` · `sre_health`) · `application/investigation_dispatcher.py`(표지 → `unresolved`+limitations) · `application/investigation_guidance.py`(`build_guidance(available_tools=…)`). 단언 `sre_agent/tests/test_plan188_toolset_availability.py`(실 holmes 닫힌 포트 · 가짜 세계 MCP 서버 꺼짐→켜짐 종단). 매뉴얼 admin 「25. 조사 트리거」 단락.
- **브리핑 형태**: 요약 `[미결] 조사 불가 — 관측 도구 연결 실패` · 원인 `판단 불가(조사 생략)` · `hypotheses` 빈 목록 · 원인 가설은 사전수집 상관·규칙 가설만 · holmes 사유는 정리(첫 줄 · 서버 모드 전용 「retry automatically」 꼬리 제거 · URL userinfo `***@`)해 limitations 1줄과 `sre_health.polestar_mcp_error`에만 · 감사 `done` 레코드에 선택 키 `tools_unavailable`(`build_briefing(investigation_skipped=True)`).
- **주의**: 폴스타(또는 APM 게이트웨이만)가 계속 다운이면 조사마다 에이전트를 1회 다시 만든다(holmes 선행검사 · 건당 최대 약 20초 · LLM 비용 0). `.env`의 `POLESTAR_MCP_URL`·토큰을 고친 경우는 설정을 기동 때 읽으므로 재기동이 필요하다. 운영자 자유 지침(`INVESTIGATION_GUIDANCE_EXTRA`)의 도구 이름은 거르지 않는다.
