  ① **후보 검색은 결정적 코드**(LLM 0 · 캐시 없음) — a 대소문자 무시 정확 · b FQDN 짧은 이름 · c IP · d K8s 워크로드 이름 토큰 LIKE 넓힘(소스당 50행) · e 확정 패턴 적용. 등급 확정 > 일치 > 유력 > 유사, 상위 5건 + 사유. 인가 존 폴스타 소스 전부 · 소스별 개별 try(실패는 「확인하지 못함」).
  ② **자동 결합은 확정(confirmed) 연결만** — 후보는 사람이 고르기 전에는 폴스타 축을 부르지 않는다(D-188 보수 원칙). 운영자 선택 = 즉시 확정 · 일반 사용자 선택 = 대기(pending · 그 조사 재조회에만 적용 · 확정을 덮지 않음 · Q5). 부정 연결 [해당 서버 없음]은 30일 만료(Q6). 패턴은 확정 연결에서만 결정적으로 뽑아 **순위·사유에만** 쓴다 — 패턴 자동 연결 없음(Q7).
  ③ **계약은 페이로드 가산 키** `meta.hints.polestar_link`(`linked`·`absent`·`unresolved`)·`meta.hints.rerun`(`parent_investigation_id`·`axes`·`prior_sections`·`prior_readings`) — `contract_version "1"` 불변 · 플래그 off면 키 없음(바이트 동일). sre_agent는 받은 사실만 쓰고 후보를 찾지 않는다(import 0 · D-139).
  ④ **소스 순위**(sre_agent): `infra_db_ids` → `linked` → `absent`(생략) → 설정 매핑 → `unresolved`(생략 · 설정 매핑 없을 때만) → 없음(결손). 플래그 on이 현행보다 나빠지지 않는다. 선택 대기·부정 연결은 「수집 결손」이 아니라 「생략」이다.
  ⑤ **재조회**는 폴스타 축 단계 + 혼합 단계(S5·S7 — 제니퍼 재호출 있음 · 의도된 유지 · 부기 1)만 다시 돌고 나머지는 부모 섹션·판독을 재사용(도구 호출 0) · 종합 재실행 · HolmesGPT 생략. 부하 상한은 수동 조사와 함께 센다(D-347).

- **부기 1 (2026-10-27 · plans/196 잔여 라운드)**:
  ㉠ 사건 종합 조사(`submit_episode_investigation`)도 대표 알람 기준으로 `meta.hints.polestar_link`를 싣는다(자동·수동과 대칭 · 플래그 off면 키 없음). 사건에 폴스타 알람이 묶여 `meta.episode.infra_db_ids`가 있으면 그 값이 연결보다 앞선다(④ 순위 그대로).
  ㉡ 저장소 쓰기(`save`·`approve`·`delete`)는 연결 키 WATCH/MULTI 트랜잭션 — 비교와 저장이 원자적이다(승인 경쟁 = 409 `link_changed` · 저장 경쟁 = 3회 재시도 뒤 503). Lua·`SET IFEQ`를 쓰지 않는 이유: 운영 Redis 버전 무관 · 판정 로직을 Python 한 곳에. 패턴 해시는 WATCH하지 않는다(다른 연결 확정으로 거짓 409 방지 · HINCRBY 자체 원자). 저장소 실패(끝내 충돌·Redis 오류)는 사용자·관리자 라우트 모두 503 `link_store_failed` + 실패 감사. Redis 연결은 소켓 타임아웃 2초.
  ㉢ 후보·연결 라우트의 사용자별 호출 상한(60초 · 후보 10 · 연결 5)은 Redis 공유 고정 창 카운터 `hostlinkrate:{route}:{sub}:{창}`(INCR+EXPIRE 한 트랜잭션 · `hostlink:*` 스캔 밖) — 서버 프로세스가 여럿이어도 한 상한. Redis 오류면 프로세스 단위 카운터로 폴백(열어 두지 않음). 고정 창이라 경계에서 최대 2배 통과 가능.
  ㉣ ⑤ 재조회의 혼합 단계(S5·S7) 제니퍼 재호출은 **유지**로 확정 — 부모 섹션은 브리핑용(`include_data=False`)이라 원자료가 없고, 원자료(제니퍼 이벤트 메시지·변경 목록)를 부모에 남기면 브리핑이 커지고 사용자 뷰 마스킹 대상(D-325 ③)이 늘어난다. 재호출 비용은 S5 이벤트 1회 + S7 변경 축 소수이고 재조회는 사용자별 상한(㉢)과 D-347 부하 상한을 탄다. 같은 사건창을 다시 읽으므로 늦게 도착한 이벤트도 반영된다. 혼합 단계를 축별 재사용으로 쪼개는 것은 단계 함수 분해가 필요해 이득 대비 크다.
