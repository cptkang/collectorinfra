- **결정일**: 2026-07-21 | **상태**: 확정 (L1 구현 완료 · Plan 60 Wave A / L3는 Plan 64 §4.8 후속)
- **배경(실측)**: 사용자 요건("어느 프로세스가 원인인지 통보")은 CPU/메모리에 한해 이미 end-to-end 기구현(Plan 47-1: enrich_processes→ProcessSnapshot→notifier 표). §16은 신규 구축이 아니라 **범위 확장**.
