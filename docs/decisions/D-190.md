## D-190. 이벤트 알람 레벨 필터 · 찾아보기 — **표시만 거른다, 수신은 건드리지 않는다**

- **결정일**: 2026-08-31 | **상태**: 확정 (구현 완료) | **번호**: `## D-` 헤더 최댓값 **D-189** · 「변경 이력」 표 최댓값 **D-189** · 「채번 이력」 표 예약(D-105·115·134·158·163~168·176) 대조 → **D-190**(2026-08-31 실측).
- **배경(사용자 지시)**: *"이벤트 알람 페이지에서 이벤트 레벨별로 필터링하여 볼 수 있는 기능과 찾아보기 기능을 추가하라."* D-182가 만든 알람 뷰는 수신 순으로 쌓기만 해서, 알람이 수십 건 쌓이면 심각 건을 눈으로 골라내야 했다.
- **결정**:
  - **필터는 표시 전용이다.** 카드를 지우지 않고 `.alarm-card-hidden`으로 감춘다(필터를 풀면 그대로 돌아온다). **미확인 배지(`alarmUnreadCount`)와 SSE 수신은 필터를 보지 않는다** — 가려진 알람을 못 본 알람으로 만들면 D-182가 지키려던 "알람을 놓치지 않는다"가 무너진다. 테스트로 고정.
  - **레벨 값은 백엔드 문자열을 그대로 쓴다.** 칩의 `data-severity`는 `severity_label`(`noise_gate/application/nodes/alarm_analyzer.py::_SEVERITY_LABELS` = 주의·경고·심각, `is_clear`면 해소)과 **같은 문자열**이다. 프런트에 별도 코드 매핑을 두지 않은 이유는 한쪽만 바뀌었을 때의 증상이 **"그 레벨 알람이 없다"와 화면상 구별되지 않기** 때문이다 — 테스트가 백엔드 상수를 import해 대조한다.
  - **검색 대상은 카드 전체 텍스트가 아니라 렌더 시점에 심는 필드 조합**(`el.dataset.search`)이다. 전체 텍스트를 긁으면 피드백 버튼 문구("유효"·"노이즈")까지 걸려 아무 키워드나 전건 매칭된다. 대상은 서버 등록명·hostname·IP·알람명·자원명·존/소스 라벨·요약·추정 원인·권고 조치.
  - **필터 상태를 저장하지 않는다.** D-178·D-180의 "개인 선호는 브라우저"와 **방향이 반대**인데, 근거는 성질이 다르기 때문이다 — 테마·표시 레벨은 되살아나도 무해하지만, **걸린 채로 되살아난 필터는 알람이 하나도 없는 화면과 구별되지 않는다**. 같은 이유로 **"모두 지우기"는 필터도 함께 푼다**(남겨 두면 다음에 도착한 알람이 조용히 가려진다).
  - **칩 건수는 키워드만 반영하고 레벨은 반영하지 않는다.** 레벨까지 반영하면 고른 칩 외에는 전부 0으로 보여 **다른 레벨로 옮겨갈 단서가 사라진다.** 건수 0인 레벨은 흐리게 표시하되(`--empty`) 누를 수는 있고, **고른 칩을 다시 누르면 해제**된다(해제하려고 "전체"를 찾아갈 필요가 없다).
  - **필터가 걸린 동안 헤더 카운트를 `표시 N / 전체 M건`으로 바꾼다.** 가려진 건수를 화면에 상시 노출해, 필터 때문에 안 보이는 것을 "알람이 없다"로 오독하지 않게 한다.
- **대안 기각**: **레벨 드롭다운(select)** — 헤더의 표시 레벨 select(D-178)와 **모양이 같아 수신 범위 설정으로 오인된다**(그쪽은 서버 구독 범위, 이쪽은 화면 필터) · **서버측 필터(알람 조회 API)** — 이력 조회 API가 없다(D-182 ①, 세션 한정 목록) · **필터에 안 걸린 카드 DOM 제거** — 필터를 풀어도 알람이 돌아오지 않는다 · **필터 상태 localStorage 저장** — 위 근거.
- **주의**: ①`severity_label`이 **"알 수 없음"**인 카드(정의되지 않은 severity·비-clear)는 레벨 칩 어디에도 걸리지 않는다 — 전체 보기에서만 보이며, 필터 중이면 `표시 N / 전체 M건`의 차이로 드러난다. 칩을 하나 더 두지 않은 것은 사용자가 요구한 "간단히"를 지키기 위한 선택이다. ②필터는 **이미 도착한 카드**에만 작용한다 — 수신 자체를 거르려면 헤더의 표시 레벨(D-178)이다. ③`app.js`·`style.css` 캐시 버전을 `v=6→7`·`v=11→12`로 올렸다(D-187).
- **구현**: `src/static/index.html`(`.alarm-tools` — 칩 5개·검색 입력·초기화) · `src/static/js/app.js`(`updateAlarmViewState` 필터 인지형 재작성 · `resetAlarmFilter` · `alarmSearchText` · `renderAlarmMessage`의 `dataset` 각인 · 칩/검색 바인딩) · `src/static/css/style.css`(`.alarm-chip` 계열 · `.alarm-search` · `.alarm-card-hidden`).
