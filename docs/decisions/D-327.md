## D-327. 조회 결과 그래프 보기 · 머리글 = 용어 사전(사전 우선 · 없으면 LLM 생성) · 값 = 결과 안 위치·의미 해석 · 표 넓게 보기

- **사용자 결정 원문**: 인터뷰(2026-10-13) — *"컬럼 헤더를 누르면 용어 사전이고 값을 누르면 값 해석으로 동작하도록 하라."* · *"사전 우선, 없으면 LLM 생성으로 하라."* · *"결과 안 위치와 의미까지만, 판정·원인 추정 분석은 별도의 계획으로 정리하라."* · 링크 위치 *"권고대로 진행하라."* · 의도 정리 *"예."* · 추가 요청 *"「질의 이력」이나 「처리현황」을 접으면 표를 넓게 볼 수 있도록 … 넓게 보기 버튼을 만들어서 표만 넓게 보는 기능도 계획에 포함시켜라."*
- **배경**: 「지난 6시간 힙 메모리 추세」 같은 시계열 답이 LLM 마크다운 표로만 보여 추세가 읽히지 않고 칼럼 뜻을 알기 어렵다. 가로로 긴 표는 말풍선 안 스크롤로만 보이며, 패널을 접어도 `.chat-messages` 920px · 답 말풍선 75% 상한 때문에 표 폭이 그대로다.
- **결정**:
  ① **그래프 보기** — 버튼 노출·축은 질문 문구가 아니라 **저장된 원본 행의 값 모양으로 코드가 결정적으로 판정**한다(LLM 미사용 · 칼럼 이름 리터럴 금지). 시계열 = 선(범주 고유값 ≤ 10이면 시리즈 분할) · 범주+수치(행 ≤ 50) = 막대 · 그 외 버튼 없음. 데이터는 `GET /query/{id}/chart`가 D-262 인가·마스킹을 거쳐 준다. 라이브러리는 Chart.js 4를 vendor 반입(폐쇄망).
  ② **링크 위치** — 그래프 패널의 **원본 데이터 격자에만** 붙인다. LLM 마크다운 답 표에는 붙이지 않는다(머리글 번역·값 가공으로 원본과 1:1 대응 불가). 링크는 전용 API → 팝오버이며 대화 턴을 만들지 않는다.
  ③ **머리글 = 용어 사전** — 조회 순서: DB 프로필 `description` → 본체 소유 `config/result_glossary.yaml`(APM 중립 키) → 없으면 LLM 생성(「사전 미등재 · LLM 생성」 표시). **LLM 생성분은 사전에 자동 등록하지 않는다**(오염 자기강화 방지 — 미적중은 로그로 남겨 사람이 보강).
  ④ **값 = 결과 안 위치·의미 해석** — 순위·최고/최저·평균 대비·시리즈 안 위치·직전 추세·같은 단위 관련 칼럼 대비 비율을 **코드가 계산**하고 LLM은 문장화만 한다. **정상/위험 판정·원인 추정은 하지 않는다**(프롬프트 금지 + 출력 어휘 가드 → 위반 시 문장 폐기·계산값만) — 판정·원인 추정 분석은 `plans/155`.
  ⑤ **입력 경계** — 해설 API는 결과에 실존하는 표·칼럼·행만 받는다(자유 텍스트 없음). LLM에는 마스킹 후 값만 보낸다.
  ⑥ **만료** — 결과 저장소(인메모리 1000건)에 없으면 404 「다시 실행」 문구. 결과 영구 저장은 별도 결정.
  ⑦ **표 넓게 보기** — 「질의 이력」·「처리 현황」 중 하나라도 접히면 대화 영역 상한을 풀고, **표·그래프 패널이 든 답 말풍선만** 폭 100%(문장 답은 75% 유지). 말풍선보다 넓은 표에는 「넓게 보기」 버튼 → 표 복제본을 전체 폭 오버레이(머리글 고정 · Esc · 포커스 복귀)로 띄운다.
  ⑧ **플래그** — ①~④는 `cfg.result_viz.chart_enabled`·`explain_enabled` 기본 off(D-162). ⑦은 **플래그 없음**(D-162 예외) — CSS·JS 표시 개선뿐이고 데이터·응답 계약을 바꾸지 않으며 되돌리기가 파일 되돌림으로 끝난다.
- **근거**: 원본 행·인가·마스킹이 이미 서버에 있다(`_results_store` · D-262) · 차트 판정과 수치 계산을 LLM에 맡기면 비결정적이다 · 판정 기준(임계치)이 본체에 없어 LLM 판정은 지어낸 답이 된다.
- **대안(기각)**: 링크가 새 대화 턴을 보냄(계획기 오분류·비용) · 마크다운 답 표에 링크(대응 불가) · 용어 전부 LLM 생성(답이 매번 달라 사전으로 못 믿음) · uPlot·SVG 직접 작성 · 문장 답까지 전폭(긴 줄 가독성).
