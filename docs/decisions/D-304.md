  Agent 호출에 `model` 인자를 넣어 바꾸지 않는다(사용자 지시가 있을 때만). effort는 사용자 설정(`~/.claude/settings.json`)을 그대로 상속한다.
  ② **자동 압축 창은 모델 단위** — `.claude/settings.json` `modelSettings`: `claude-opus-5-5` 300,000 · `claude-sonnet-5-5` 200,000. Opus 5.5·Sonnet 5.5는 둘 다 기본 창이 1M(native)이라 **`model` 지정만으로는 창이 줄지 않는다**. Claude Code는 창을 에이전트별로 줄 수 없고 모델별로만 주므로 Opus 300K는 **메인 세션에도 걸린다**(사용자 확인). 정식 모델명이 키이고 `[1m]`·날짜 표기를 함께 묶는다 — Opus·Sonnet 새 버전으로 바뀌면 키를 갱신한다.
  ③ **위임 원칙** — 서브에이전트 하나에 작업 하나(계획서 하나 또는 Wave 하나), 다음 작업은 새 에이전트. `SendMessage` 재개는 같은 작업의 교정에만. 위임 프롬프트에 대상 파일·D-번호·계획서 절을 직접 적고 문서 전체를 읽히지 않는다. 보고는 요약(바꾼 파일·검증·잔여)으로 받는다. 정본은 `.claude/agents/team-lead.md` 「위임 원칙」.
  ④ **결정 로그 구조** — `docs/02_decision.md`는 쓰는 법과 한 줄 색인만, 본문은 `docs/decisions/D-NNN.md` 한 건씩, 변경 이력은 `docs/decisions/CHANGELOG.md`, 분리 이전 채번 기록은 `docs/decisions/NUMBERING.md`(동결). **채번 = 색인 표(예약 행 포함) 최댓값 + 1, 예약은 색인에 `예약` 행** — D-161 부기의 「안내 라인 등재」와 「`## D-` 헤더·변경 이력·채번 이력 세 곳 grep」을 대체한다. 분리는 줄 단위 무손실(원문 비공백 3,782줄 = 분리본 3,782줄 · 누락 0 · 추가 0).
