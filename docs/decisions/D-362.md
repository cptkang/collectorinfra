- **배경**: 사용자 지시(2026-11-03) *"제니퍼 인스턴스 네임으로 domain_name, domain_description을 조회하여 나온 값과 itam의 업무 정보, 서비스 정보등을 확인하여 해당 호스트의 ip를 검색한다. 이 검색된 정보를 내부 db에서 apm, sms 연계 정보를 관리하고 … 연계 정보는 운영자가 관리 할 수 있게 하여 …"* → 개정 1(사전 스캔) · 개정 2(관리자 수동 실행만) · 개정 3 *"매핑정보가 없으면 직접 조회하지만 매핑정보가 있으면 DB에서 조회하여 장애 진단 속도를 높이는 목적"*. 인터뷰 I-1~I-7 확정 · 잔여 Q3·Q4·Q6·Q7·Q9는 권고안 「이의 없으면 확정」 제시 후 구현 지시로 확정(`plans/210` §8). 폐쇄망 `.env`에 `JENNIFER_NODE_ADDRESS_ENABLED`·웹 계정이 비어 `hostAddress`가 호출되지 않았다(§0).
- **결정**:
  ① **목적 = 진단 속도** — `_attach_polestar_link`(자동·사건·수동 공통)가 연계 매핑을 먼저 본다. 순서(첫 성립에서 멈춤): 0 사용자 선택 → 1 매핑 manual·verified(instance→workload→domain) → 2 매핑 auto instance → 3 페이로드 노드 주소(`host_address_status=ok`) → SMS IP 색인(1대일 때만) → 3′ 색인 miss면 `node_address_link` 직접 조회 → 4 매핑 auto workload/domain(대상 전부 ≤10) → 5 VM 인스턴스 IP·이름 → 색인 → miss면 정확 일치 프로브(1대만) → 6 D-348 저장 확정 연결 → 7 미확정 사유 + ITAM 생성 요청(비동기). 1·2·4는 Redis `HMGET` 1회. 3′·5 직접 조회는 합계 예산(`NOISE_APM_HOST_MAP_LIVE_BUDGET_SECONDS` 5초). 판정마다 로그 `apm_map_lookup source= order= scope= result=hit|index|live|miss ms=`.
  ② **D-348 ② 예외** — 자동 생성 매핑(노드 주소·VM 정확 일치·ITAM 업무 추정)은 사람 확인 없이 진단에 쓴다(I-1 「폴스타 축 없이 끝나는 것이 더 나쁘다」). 근거 「자동 · 추정」을 화면·조사 근거에 상시 표기한다. VM 정확 일치 1대 자동 연결도 이 예외에 든다(D-355 ⑤ VM 제외는 이 플래그 on일 때만 완화). `ambiguous`·`failed`·`target_gone`은 쓰지 않는다.
  ③ **저장 = PG 정본 + Redis 읽기 사본·색인**(Q3) — `apm_host_map`(UNIQUE `source_id, domain_id, scope, match_key` · `version` 낙관적 동시성) · 실행 기록 `apm_host_map_scan_run` · 스냅샷 4표 + 현재 포인터(성공 스캐너만 교체). Redis `apmhostmap:{source_id}` 해시(`{scope}|{domain_id}|{match_key}`) · `apmhostmap:smsip`·`apmhostmap:smshost` 색인. **기록자는 API 프로세스뿐**(D-049) — 워커는 되적재·사용 기록을 Redis Stream `apmhostmap:req`(`learn`·`touch`·`itam_request`)로 넘기고 API 소비자(consumer group)가 upsert한다. 사본이 비면 결과는 miss(직접 조회)일 뿐 오연결이 없다.
  ④ **키 3단**(Q4) — `instance`(정규화 파드명/인스턴스명 · 파드 생애 동안 노드 고정) → `workload`(`k8s_workload_name` · 노드 집합 합집합 ≤10) → `domain`(ITAM 추정 기본값). auto instance 행 30일 · auto 행 180일 미관측 정리.
  ⑤ **쓰기 규칙** — 자동은 `origin=auto AND verified=false AND state<>'disabled'`만 갱신한다. 관리자가 고친 행(`origin=manual`)·확인한 행(`verified`)·「연계 없음」(`disabled` → 힌트 `absent`)은 자동이 덮지 않고 결과가 다르면 `scan_suggests`만 남긴다.
  ⑥ **ITAM 사슬은 스냅샷 메모리 대조** — 도메인명·설명 토큰(일반어 제외) → 업무(코드 정확 → 명 정확 → 명 포함) → 0건이면 서버 자유 기재 칸 포함 → ITAM 서버(상한 50 · 초과 `ambiguous`) → 폴스타 정확 일치 → 1~10 `active` · 0 `failed` · 업무별로 갈림 `ambiguous`. 외부 입력(도메인명·설명)은 SQL에 들어가지 않는다. 표·칼럼·일반어는 `config/knowledge/itam/service_host_lookup.yaml`(추정 — W0-4 확정 대기 · Q7).
  ⑦ **사전 스캔은 관리자 수동 실행만**(I-6) — 관리자 탭 「지금 스캔」 → 백그라운드 · Redis 단독 락(`SET NX EX 3600` + 30초 연장 · 실행 중 409 `scan_running`) · 스캐너 4종(APM 인벤토리 · APM 노드 주소 · SMS 존별 키셋 페이지 · ITAM) 개별 try · 실패 스캐너는 이전 스냅샷 유지 · DPM은 `not_integrated` 고정(Q9 · D-341 ⑤ 슬롯). 모든 관측 DB SQL은 코드가 조립한 고정 SELECT(LLM 0) · readonly MCP · `sql_guard`.
  ⑧ **`hostAddress` 호출 경로 4종**(I-4) — 알람(현행 폴러) · 스캔·채팅용 게이트웨이 도구 `apm_node_addresses(source_ids, domain_ids)`(**`JENNIFER_NODE_ADDRESS_ENABLED=true`일 때만 등록** — off면 도구 목록 비트 동일) · 조사(힌트로 전달 · 추가 호출 없음) · 채팅 보기 `apm.node_address`(닫힌 보기 목록 — D-300 ⑧ 단어 매칭 0 · 미등록이면 「게이트웨이 노드 주소 조회 비활성」 사유 답). 노드 주소를 못 읽은 사유는 힌트 `node_address_status`로 노출한다(침묵 금지).
  ⑨ **계약은 가산 키**(`contract_version "1"` 불변) — linked `basis:"apm_map"` + `map_origin`·`map_scope`·`map_id`·`map_basis`·`resource_id`·`evidence_text` · 여러 대 `targets[]`(≤10 · 최상위는 첫 대상) · unresolved `reason: apm_map_pending|failed|no_inventory|ambiguous` + `no_config_fallback: true`(sre_agent는 설정 매핑 대체 금지 — D-355 ④ 일반화) · 파드면 `pod: true`(화면 선택 UI 미개방 · D-355 ④) · `targets[].kind != "sms"`는 무시(DPM 대비). sre_agent는 대상이 여럿이면 지표 단계(S4)와 사전 수집 지표를 대상마다 돌리고 이상 대상을 짚는다.
  ⑩ **관리자만 관리**(I-5) — `/api/v1/admin/apm-host-map`(목록·수동 추가(폴스타 실재 확인)·수정·확인·다시 찾기 미리보기/적용(관리자별 분당 10회)·삭제·스캔·인벤토리) · `require_admin_user` + role 재검증 · 전 동작 `log_admin_event` before/after · 화면 `textContent`만. 일반 사용자는 진단 화면에서 근거만 본다. D-348 진단 화면 선택 흐름은 v1 병존(Q6 · 6순위).
  ⑪ **플래그 6키 전부 기본 off/현행**(`NOISE_APM_HOST_MAP_ENABLED`·`_AUTO_ENABLED`·`_MAX_TARGETS` 10·`_LIVE_BUDGET_SECONDS` 5·`_RETRY_HOURS` 24·`_SCAN_PAGE_ROWS` 1000(<10000)) — off면 DDL·태스크·라우트·탭·힌트 키 0(비트 동일). `_AUTO_ENABLED` off면 관리자 수동 매핑만 쓴다(되적재·스캔·ITAM 요청 없음).
