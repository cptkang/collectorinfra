- **결정**:
  ① **병합 키는 정규화 값이다** — `_identity_key()`(소문자 + `[\s_.-]` 제거)로 잡는다. `SV-WEB-001`·`svweb001`·`sv_web_001`은 같은 서버다. 표시 값은 슬롯을 처음 만든 조회의 원시 표기형을 유지한다.
  ② **공통 서버가 하나도 없으면 결정적 병합을 하지 않는다** — `None`을 반환해 LLM 합성으로 폴백한다(INFO 로그). 독립 조회의 outer join 표는 절반이 빈 칸이고, 그 위의 절단이 한쪽을 통째로 지운다.
  ③ **base 스코프 절단은 좁히기일 때만 한다** — `base_keys ⊆ (다른 조회들의 키 합집합)`일 때만 절단한다. 일부만 겹치면 절단하지 않아, **어느 조회에도 없는 서버를 남기려다 다른 조회에만 있는 서버를 지우는 일**이 없다.
  ④ **도구 호출 순번은 collector 길이가 아니라 전용 카운터다** — `build_tools`가 도구 묶음마다 `itertools.count(1)`을 만들어 모든 도구가 공유하고, `_run_subagent_tool(order_seq=…)`이 **호출 시작 시점**에 `next()`로 받는다.
