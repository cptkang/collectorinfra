# PII 필터링 규칙

아래 정규표현식과 일치하는 문자열은 개인정보(PII)로 판단하여 필터링한다.

## 1. 주민등록번호

- 룰 ID: `848`
- 탐지 예시:
  - `8809161111111`
  - `880916-1111111`
  - `880229 2111111`

```regex
(?<!\d)(?:(?:[5-9]\d)(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])[- ]?[12]\d{6}|(?:[0-4]\d)(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])[- ]?[34]\d{6})(?!\d)
````

## 2. 법인등록번호

* 룰 ID: `854`
* 탐지 예시:

  * `180213-2111111`

```regex
(?<!\d)(?:(1[1-9]|2[0-8])(0[1-3]|1[1-5]|4[1-9]|5[0-9]|6[0-2])(1[1-5]|2[1-2]|3[1-9]|4[0-9]|5[0-5]|6|7|8[1-6])(?:[-\s]\d{7}))(?!\d)
```

## 3. 외국인등록번호

* 룰 ID: `849`
* 탐지 예시:

  * `121210-5234567`
  * `121210 5234567`

```regex
(?<!\d)\d{2}(?:0[1-9]|1[0-2])(?:0[1-9]|[12]\d|3[01])[- ]?[5678]\d{6}(?!\d)
```

## 4. 운전면허번호

* 룰 ID: `850`
* 탐지 예시:

  * `12-11-222222-33`
  * `서울 12 121058 50`
  * `11 12-121058-50`

```regex
(?<!\d)(?:(?:서울|부산|경기|강원|충북|충남|전북|전남|경북|경남|제주|대구|인천|광주|대전|울산|1[1-9]|2[0-8])[- ]?\d{2}[- ]\d{6}[- ]\d{2}|(?:서울|부산|경기|강원|충북|충남|전북|전남|경북|경남|제주|대구|인천|광주|대전|울산|1[1-9]|2[0-8])[- ]\d{10})(?!\d)
```

## 5. 여권번호

* 룰 ID: `842`
* 탐지 예시:

  * `D24689033`
  * `M15687911`

```regex
(?<!\d)(?:[MSROD]\d{8}|[MSROD]\d{3}[A-Z]\d{4})(?!\d)
```

## 6. 핸드폰번호

* 룰 ID: `855`
* 탐지 예시:

  * `01012345678`
  * `010 1234 5678`
  * `010-1234-5678`

```regex
(?<!\d)(01[016789])(?:[-\s]*\d{7,8})(?!\d)
```

## 7. 계좌번호

* 룰 ID: `851`
* 탐지 예시:

  * `6565-01-02-233123`
  * `6471 01 02 233123`
* 숫자 개수: 10~14자리
* `:` 또는 `~`가 포함된 문자열은 제외한다.

```regex
^(?!.*\b\d{2}[-\s]\d{2}[-\s]\d{3}[-\s]\d{5}\b)(?!.*[:~])(?=(?:\D*\d){10,14}\D*$).*?(?<!\d)(?:\d+(?:-\d+)+|\d+(?: \d+)+)(?!\d)[^\d]*$
```

## 8. 카드번호

* 룰 ID: `852`
* 탐지 예시:

  * `1234-5678-7854-1234`
  * `1234 5678 7854 1234`
* 네 자리 숫자 그룹 사이에는 동일한 구분자를 사용해야 한다.

```regex
(?<!\d)\d{4}([-\s])\d{4}\1\d{4}\1\d{4}(?!\d)
```

## 9. 이메일 주소

* 룰 ID: `853`
* 탐지 예시:

  * `abcd123@google.co.kr`
  * `edd123@naver.com`
* 필터링 제외 도메인:

  * `kbonecloud.com`
  * `kbfg.com`

```regex
[A-Za-z0-9]+(?:[._%+-][A-Za-z0-9]+)*@(?!(?:kbonecloud\.com|kbfg\.com)\b)[A-Za-z0-9]+(?:-[A-Za-z0-9]+)*(?:\.[A-Za-z0-9]+(?:-[A-Za-z0-9]+)*)+
```

## 판정 기준

입력 내용에서 위 정규표현식과 일치하는 문자열이 발견되면 다음 PII 유형 중 하나로 판정한다.

* 주민등록번호
* 법인등록번호
* 외국인등록번호
* 운전면허번호
* 여권번호
* 핸드폰번호
* 계좌번호
* 카드번호
* 이메일 주소

정규표현식과 일치하지 않거나 명시된 제외 조건에 해당하면 해당 PII 유형으로 판단하지 않는다.
